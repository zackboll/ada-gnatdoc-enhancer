Description

Explicit independent copies between Mat and UMat. Each operation makes an independent copy: no storage, header or native handle is shared between the source and the result, and later changes to one do not affect the other. These non-primitive operations live in a child package because Ada cannot dispatch simultaneously on Mat and UMat.

To_Mat

function To_Mat (Self : UMat) return Mat

Copies the elements of Self into a newly allocated host Mat. The result owns its own storage and does not share data with Self.

Parameters
Self

The UMat to copy.

Return Value

A new Mat holding a copy of Self's elements.

Raised exceptions
OpenCV_Error

Raised when the native copy fails.

To_UMat

function To_UMat (Self : Mat) return UMat

Copies the elements of Self into a newly allocated UMat. The result owns its own UMat storage and does not share data with Self. Whether OpenCL is used for the resulting UMat is a native decision and is not guaranteed.

Parameters
Self

The Mat to copy.

Return Value

A new UMat holding a copy of Self's elements.

Raised exceptions
OpenCV_Error

Raised when the native copy fails.
