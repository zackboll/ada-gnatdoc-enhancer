Description

Checked element access to single-channel Float16 (CV_16FC1) Mats. Each element is one Float16_Value, the exact stored IEEE-754 binary16 bit pattern: signed zeros, subnormals, infinities and NaN payloads are preserved and no numeric conversion is performed. Every operation validates the Mat's depth, channel count, dimension count and indices before touching storage and raises OpenCV_Error on any mismatch, so a wrong Mat type is never reinterpreted. Indices are zero-based. Writes go to the Mat's actual storage, so every shallow alias and the parent of a Region observe them.

Get

function Get (Image : Mat; Indices : Index_Array) return Float16_Value

Zero-based N-dimensional access. Indices'Length must equal Image.Dimension_Count. Iteration order maps to OpenCV dimensions regardless of the array's index bounds. The exact stored bit pattern is returned.

Parameters
Image

A Float16 Mat with exactly one channel and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Return Value

The stored element value, with its exact binary16 bits.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float16 single-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.

Get

function Get (Image : Mat; Row, Column : Integer) return Float16_Value

Reads the element at a zero-based row and column of a two-dimensional Mat. The exact stored bit pattern is returned.

Parameters
Image

A two-dimensional Float16 Mat with exactly one channel.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Column

Zero-based column, in 0 .. Image.Columns - 1.

Return Value

The stored element value, with its exact binary16 bits.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float16 single-channel two-dimensional Mat, or Row or Column is outside the Mat.

Set

procedure Set
  (Image : in out Mat; Indices : Index_Array; Value : Float16_Value)

Zero-based N-dimensional write; the indexing rules of the matching Get apply. The exact bit pattern of Value is stored in the Mat's actual storage and is visible through every header sharing it.

Parameters
Image

A Float16 Mat with exactly one channel and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Value

The element value to store; its bits are kept exactly.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float16 single-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.
