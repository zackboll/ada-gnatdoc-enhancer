Description

Fixed-size, value-semantic matrix with compile-time dimensions.

Instantiating this package fixes the element type and both dimensions. Indices are zero-based and elements are addressed as (Row, Column). This describes logical indexing only; no native memory layout is implied.

Matrix is an ordinary Ada array and this generic does not introduce an OpenCV native handle of its own. Array assignment follows Ada assignment semantics for the actual element type. Element copying, adjustment, finalization, and resource ownership depend on the type supplied when the generic is instantiated.

Element_Type is the type of each element. Row_Count and Column_Count are the dimensions and must be positive; valid row indices are 0 through Row_Count - 1 and valid column indices are 0 through Column_Count - 1.

Matrix

type Matrix is array (Row_Index, Column_Index) of Element_Type;

Matrix of Row_Count rows and Column_Count columns. Element (Row, Column) is addressed with zero-based indices in the ranges Row_Index and Column_Index. Row_Index'Range and Column_Index'Range are the array bounds.
