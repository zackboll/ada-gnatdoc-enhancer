Description

Binding implementation interface for cooperating OpenCV Ada module crates. This is not an ordinary application API.

Each handle is valid only during its callback. A module implementation passes it only to its private C interop layer; it neither owns nor retains the associated native Mat header.

Input_Mat_Handle

type Input_Mat_Handle is private;

Read-only native Mat handle for cooperating module crates. It is valid only during the callback that receives it and is neither owned nor retained by the receiver.

Input_UMat_Handle

type Input_UMat_Handle is private;

Read-only native UMat handle. UMat handles have the same callback-only lifetime as the Mat handles. A cooperating module may pass them only to its private native interop layer. Core owns both the opaque wrapper and original cv::UMat header: do not delete the header or retain its pointer after the callback/call scope. No public native pointer escapes and no ownership transfer, Mat conversion, or mapping occurs. All module shims must use a compatible OpenCV ABI/installation with Core.

Output_Mat_Handle

type Output_Mat_Handle is private;

Writable native Mat handle for cooperating module crates. It exposes the actual Core header, which an output operation may rebind, and is valid only during the callback that receives it.

Output_UMat_Handle

type Output_UMat_Handle is private;

Writable native UMat handle with the same callback-only lifetime and ownership rules as Input_UMat_Handle. It exposes the actual Core-owned header, which an output operation may rebind.

With_Input_Handle

procedure With_Input_Handle
  (Image   : Mat;
   Process : not null access procedure (Handle : Input_Mat_Handle))

Invokes Process with an input handle for Image's native header. The handle is valid only during Process; it must not be stored or used afterwards. No elements are copied. Exceptions raised by Process propagate unchanged.

Parameters
Image

The Mat whose native header is borrowed.

Process

Callback that receives the borrowed handle.

With_Output_Handle

procedure With_Output_Handle
  (Image   : in out Mat;
   Process : not null access procedure (Handle : Output_Mat_Handle))

Invokes Process with an output handle for Image's actual Core header, so a native operation may recreate or rebind it in place. The header is resolved before Process runs; in particular a temporary external-buffer view is rejected, because its header cannot safely be rebound by an OutputArray operation. The handle is valid only during Process and must not be stored or used afterwards. Exceptions raised by Process propagate unchanged.

Parameters
Image

The Mat whose native header is borrowed for writing.

Process

Callback that receives the borrowed handle.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when the header cannot be used as an output, such as a temporary view.
