Description

Typed access to one complete CV_16SC2 SparseMat element. Components are OpenCV channel indices 0 .. 1; no semantic meaning is assigned. Each operation validates that the matrix is allocated and has exactly this depth and two channels, then validates the coordinates, and raises OpenCV_Error on any mismatch. Coordinates are zero-based, one per dimension. A missing coordinate reads as an all-zero vector but is not the same as a stored all-zero vector. Writes go to the shared nodes, so every shallow alias of the Sparse_Mat observes them.

For_Each_Stored

procedure For_Each_Stored
  (Image   : Sparse_Mat;
   Process :
     not null access procedure
       (Indices : Index_Array; Value : OpenCV.Core.Int16_Vec2.Vector))

Stored nodes only; unspecified order; values are copies. Do not structurally mutate Image or aliases during callbacks. Indices have bounds 1 .. Dimension_Count and are zero-based.

Parameters
Image

An allocated Int16 Sparse_Mat with exactly two channels.

Process

Callback invoked once for each stored node, including explicitly stored all-zero vectors, with that node's coordinates and value.

Raised exceptions
OpenCV_Error

Raised before any callback when Image is unallocated or has another depth or channel count, and also raised if the native iteration fails, which can happen after earlier callbacks have already run.

Get

function Get
  (Image : Sparse_Mat; Indices : Index_Array)
   return OpenCV.Core.Int16_Vec2.Vector

Missing nodes read as an all-zero vector and are not created.

Parameters
Image

An allocated Int16 Sparse_Mat with exactly two channels.

Indices

One zero-based index per dimension, each less than the matching extent.

Return Value

The stored vector, or an all-zero vector when no node is stored there.

Raised exceptions
OpenCV_Error

Raised when Image is unallocated or has another depth or channel count, Indices does not have exactly Dimension_Count entries, or an index is out of bounds, or OpenCV reports a failure.
