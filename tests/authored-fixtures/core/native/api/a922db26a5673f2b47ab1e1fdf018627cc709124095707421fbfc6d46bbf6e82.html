Description

Whole-row access to three-channel UInt8 (CV_8UC3) two-dimensional Mats, by copy (Read_Row, Write_Row) or by a zero-copy callback-scoped view (With_Read_Only_Row, With_Writable_Row). Each row element is one complete OpenCV.Core.UInt8_Vec3.Vector. Row and column indices are zero-based. Every operation validates the Mat's depth, channel count, row index and row length and raises OpenCV_Error on any mismatch.

Column_Index

subtype Column_Index is Natural;

Zero-based column position within a row.

Read_Row

procedure Read_Row (Image : Mat; Row : Natural; Data : out Row_Array)

Copies one row of Image into Data. Data'Length must equal Image.Columns; Data (Data'First) receives column 0 and the array's index bounds are otherwise irrelevant. Image is unchanged and Data owns its values.

Parameters
Image

A two-dimensional UInt8 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Data

Receives one three-channel pixel per column.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt8 three-channel two-dimensional Mat, Row is outside the Mat, or Data'Length differs from Image.Columns. Also raised when Data'Length exceeds Natural'Last / 3: copied rows use an intermediate buffer of three scalar channels per vector. This limit does not apply to the zero-copy row callbacks.

Row_Array

type Row_Array is array (Natural range <>) of OpenCV.Core.UInt8_Vec3.Vector;

The pixels of one Mat row, one UInt8_Vec3.Vector per column. Array bounds are the caller's choice: only the length matters, and the first array element always corresponds to column 0. The zero-copy callbacks pass arrays whose bounds are 0 .. Image.Columns - 1.

With_Read_Only_Row

procedure With_Read_Only_Row
  (Image   : Mat;
   Row     : Natural;
   Process : not null access procedure (Data : aliased Row_Array))

Invokes Process with a zero-copy view of one UInt8 C3 Mat row. Data directly aliases native OpenCV storage for that logical row; no pixel values are copied. Each Data element is one complete interleaved C3 pixel: Data (Column) (0 .. 2) are the three native UInt8 channels. The explicitly aliased callback formal guarantees that Data is passed by reference and directly denotes the borrowed Mat row for the duration of Process. The ordinary lifetime of the view is the callback. Data is indexed with zero-based Mat columns: Data'First = 0, Data'Last = Image.Columns - 1, and Data'Length = Image.Columns. Only the active row elements are exposed, never inter-row padding. Non-contiguous Regions are supported because each 2-D logical row remains a contiguous sequence even when the parent stride is larger. The implementation holds a shallow Mat lease for the callback so referenced storage cannot disappear merely because another header is rebound or finalized. That lease is deterministic memory management, not thread synchronization. Do not retain a reference or address of Data after Process returns. Read-only access performs no copy; if another alias mutates the shared storage during the callback, Data observes those changes according to ordinary aliasing rules. Image.Is_Continuous is not required.

Parameters
Image

A two-dimensional UInt8 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Process

Callback that receives the borrowed row. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a two-dimensional UInt8 three-channel Mat or Row is outside the Mat.

With_Writable_Row

procedure With_Writable_Row
  (Image   : in out Mat;
   Row     : Natural;
   Process : not null access procedure (Data : aliased in out Row_Array))

As With_Read_Only_Row, except Process receives an in-out view. Writes through Data mutate the actual Mat storage immediately. There is no write-back phase. A write through Data is visible through Image and any shallow alias before Process returns, and a write through another alias is immediately visible through Data. Exceptions raised by Process propagate unchanged; any writes completed before the exception remain visible.

Parameters
Image

A two-dimensional UInt8 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Process

Callback that receives the borrowed row for reading and writing. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a two-dimensional UInt8 three-channel Mat or Row is outside the Mat.

Write_Row

procedure Write_Row (Image : in out Mat; Row : Natural; Data : Row_Array)

Copies Data into one row of Image. Data'Length must equal Image.Columns; Data (Data'First) is stored in column 0. The values are written to the Mat's actual storage, so shallow aliases and the parent of a Region observe them.

Parameters
Image

A two-dimensional UInt8 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Data

One three-channel pixel per column.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt8 three-channel two-dimensional Mat, Row is outside the Mat, or Data'Length differs from Image.Columns. Also raised when Data'Length exceeds Natural'Last / 3: copied rows use an intermediate buffer of three scalar channels per vector. This limit does not apply to the zero-copy row callbacks.
