Description

Runtime-typed sparse N-dimensional matrix backed by a native OpenCV cv::SparseMat. Unlike a dense Mat, only explicitly stored elements (the nodes) occupy memory and are visited by the reductions here; a missing coordinate is not the same as a stored zero, although both read as zero through the typed Get operations. Each Sparse_Mat object is a controlled header that owns its native resource. Ada assignment is shallow: the target receives its own header while the nodes stay shared and reference counted, so a write through one header is visible through the other. Clone makes an explicit deep copy. A default Sparse_Mat is unallocated: it reports zero dimensions and most operations reject it with OpenCV_Error. Sparse_Mat has no Region or view operations and is not interchangeable with Mat or UMat.

Clear

procedure Clear (Self : in out Sparse_Mat)

Removes every stored node while keeping the shape and element type, so every coordinate becomes missing and an allocated Sparse_Mat stays allocated. Clearing a default (unallocated) Sparse_Mat is accepted and leaves it unallocated. Other headers that share Self's nodes through assignment observe the cleared matrix as well; a Clone is unaffected.

Convert_To

function Convert_To
  (Self : Sparse_Mat; Depth : Depth_Type; Scale : Long_Float := 1.0)
   return Sparse_Mat

Native SparseMat::convertTo into an independent Sparse_Mat. Shape and channel count are preserved. Only stored nodes are converted, including an explicitly stored zero; missing coordinates stay missing. Each stored component becomes saturate_cast (source * Scale) at Depth. There is no offset. Scale 1.0 uses OpenCV's unscaled conversion. Float16 is not a supported source or destination: OpenCV 4.1 through 5.0 leave both directions null in the sparse conversion tables, and this binding does not substitute a Float32 fallback. Float16 Get/Set bit preservation is unchanged.

Parameters
Self

The allocated Sparse_Mat to convert.

Depth

Depth of the stored components of the result.

Scale

Factor applied to each stored component before saturation.

Return Value

A new Sparse_Mat with independent storage.

Raised exceptions
OpenCV_Error

Raised when Self is unallocated, either depth is Float16, or OpenCV reports a failure.

Create

function Create
  (Shape : Dimension_Array; Element_Type : Mat_Type) return Sparse_Mat

Creates an allocated sparse matrix with no stored nodes. Shape is read in iteration order, independent of its index bounds: the first element is the extent of native dimension 0. Between 2 and 32 dimensions are required, and every extent must be positive. Element_Type fixes the depth and channel count of every stored element. Every coordinate is initially missing, and the matrix owns its storage independently.

Return Value

A new, empty, allocated Sparse_Mat.

Raised exceptions

From_Dense

function From_Dense (Source : Mat) return Sparse_Mat

Converts a dense Mat into an independent Sparse_Mat of the same shape, depth and channel count. Only elements that are not entirely zero are stored; an element is omitted when all of its stored bytes are zero, so a Float16 negative zero (16#8000#) and a NaN are stored. A multi-channel element is stored as a whole when any channel is nonzero. The result does not share storage with Source, and later changes to either do not affect the other. Non-contiguous Regions are accepted.

Parameters
Source

The nonempty dense Mat to convert.

Return Value

A new Sparse_Mat holding the nonzero elements of Source.

Raised exceptions
OpenCV_Error

Raised when Source is empty or OpenCV reports a failure.

Min_Max_Loc

function Min_Max_Loc (Self : Sparse_Mat) return Sparse_Extrema

Finds the extrema among the stored nodes of Self; the full contract, including ties, NaN, infinities and unestablished sides, is described with Sparse_Extrema. Only stored nodes participate: missing coordinates are not created, and an explicitly stored zero is a candidate. Self is not modified.

Parameters

The allocated single-channel Float32 or Float64 matrix.

Return Value

The extrema and their zero-based coordinates.

Raised exceptions
OpenCV_Error

Raised for an unallocated, multi-channel, integer or Float16 layout, or an OpenCV failure.

Norm

function Norm (Self : Sparse_Mat; Kind : Norm_Kind := L2) return Long_Float

Native sparse cv::norm over stored nodes only. Missing coordinates contribute zero and are not created. An explicitly stored zero contributes zero and remains a node. The matrix is not modified. Requires an allocated Float32 or Float64 matrix with exactly one channel. An allocated matrix with no stored nodes returns 0.0. L1 is the sum of absolute stored values, L2 is the square root of the sum of their squares, and Infinity is the maximum absolute stored value. Multi-channel, integer, and Float16 layouts are rejected before the ABI call. Min_Max is not a sparse norm.

Parameters
Self

The allocated single-channel Float32 or Float64 matrix.

Kind

L1, L2 or infinity norm.

Return Value

The norm of the stored nodes.

Raised exceptions
OpenCV_Error

Raised for an unallocated, multi-channel, integer or Float16 layout, or an OpenCV failure.

Normalize

function Normalize
  (Self        : Sparse_Mat;
   Target_Norm : Long_Float := 1.0;
   Kind        : Norm_Kind := L2) return Sparse_Mat

Native sparse cv::normalize into an independent Sparse_Mat. Shape, depth, channel count, and stored-node coordinates are preserved, including explicitly stored zeros. Values are scaled by Target_Norm / Norm when that norm exceeds OpenCV's DBL_EPSILON; otherwise the scale is 0.0 and every stored value becomes zero while its node remains stored. An allocated matrix with no nodes stays empty. A negative Target_Norm is native and deterministic: it reverses the sign of every stored value. The source is unchanged. The same Float32/Float64 single-channel restriction as Norm applies. Min_Max normalization is unavailable because shifting implicit zeros would change sparse semantics.

Parameters
Self

The allocated single-channel Float32 or Float64 matrix.

Target_Norm

Norm the stored values are scaled to.

Kind

L1, L2 or infinity norm.

Return Value

A new Sparse_Mat with independent storage.

Raised exceptions
OpenCV_Error

Raised for an unallocated, multi-channel, integer or Float16 layout, or an OpenCV failure.

Sparse_Extrema

type Sparse_Extrema is record
   Has_Minimum      : Boolean := False;
   Has_Maximum      : Boolean := False;
   Minimum          : Long_Float := 0.0;
   Maximum          : Long_Float := 0.0;
   Minimum_Location : Index_Array (1 .. 32) := (others => 0);
   Maximum_Location : Index_Array (1 .. 32) := (others => 0);
   Dimensions       : Natural := 0;
end record;

Native sparse cv::minMaxLoc over stored nodes only. Requires an allocated Float32 or Float64 matrix with exactly one channel. Missing coordinates do not participate and are not created. An explicitly stored zero is a candidate. Comparisons use strict < and >, so the earliest node in OpenCV's hash traversal that holds an equal extremum is reported. That order is unspecified and is not insertion order. Negative zero compares equal to positive zero. NaN never replaces a finite extremum. Has_Minimum and Has_Maximum are independent: each is True only when native OpenCV wrote that location. Empty storage and a NaN-only matrix establish neither. Positive infinity and a stored Float32 FLT_MAX or Float64 DBL_MAX establish only the maximum, because neither is strictly less than OpenCV's initial minimum. Negative infinity and a stored -FLT_MAX or -DBL_MAX establish only the minimum. A side that was not established returns 0.0 and an all-zero location; the native initialization sentinels are not public extrema. Each location is a fixed 32-coordinate array; only elements 1 .. Dimensions are meaningful, and those values are the zero-based OpenCV coordinates. The matrix is not modified. Integer, Float16, multi-channel, and unallocated layouts are rejected before the ABI call. Min_Max normalization remains unavailable.

Record fields
Has_Minimum

True when Minimum and Minimum_Location were written by native OpenCV.

Has_Maximum

True when Maximum and Maximum_Location were written by native OpenCV.

Minimum

Smallest stored value found. Meaningful only when Has_Minimum is True.

Maximum

Largest stored value found. Meaningful only when Has_Maximum is True.

Minimum_Location

Zero-based coordinates of the minimum, in entries 1 .. Dimensions; remaining entries are zero. Meaningful only when Has_Minimum is True. The array has fixed capacity 32.

Maximum_Location

Zero-based coordinates of the maximum, in entries 1 .. Dimensions; remaining entries are zero. Meaningful only when Has_Maximum is True. The array has fixed capacity 32.

Dimensions

Number of matrix dimensions, which is how many leading entries of each location array are meaningful.

To_Dense

function To_Dense (Self : Sparse_Mat) return Mat

Converts Self into an independent dense Mat of the same shape, depth and channel count. Stored nodes are copied and every missing coordinate is zero. Self is unchanged and the result owns independent storage. The conversion is rejected when the dimension count exceeds the native dense Mat capacity (10 on OpenCV 5.0).

Parameters
Self

The allocated Sparse_Mat to expand.

Return Value

Raised exceptions

Raised when Self is unallocated, has too many dimensions for a dense Mat, or OpenCV reports a failure.

To_Dense

function To_Dense
  (Self   : Sparse_Mat;
   Depth  : Depth_Type;
   Scale  : Long_Float := 1.0;
   Offset : Long_Float := 0.0) return Mat

Native SparseMat::convertTo into an independent dense Mat. Shape and channel count are preserved. A stored component becomes saturate_cast (source * Scale + Offset). A missing element is initialized with OpenCV Scalar (Offset): channel 0 receives Offset and every later channel receives 0, because Scalar supplies one value and three zeros. Float16 source and destination depths are rejected for the same OpenCV 4.1-5.0 table gap as Convert_To. On OpenCV 5, dimension counts above the native dense Mat capacity are rejected before conversion.

Parameters
Self

The allocated Sparse_Mat to expand.

Depth

Depth of the dense result.

Scale

Factor applied to each stored component.

Offset

Value added to each stored component, and used to initialize channel 0 of every missing element.

Return Value

A new dense Mat with independent storage.

Raised exceptions
OpenCV_Error

Raised when Self is unallocated, either depth is Float16, the dimension count exceeds the dense Mat capacity, or OpenCV reports a failure.
