Description

Typed access to four-channel signed 8-bit (CV_8SC4) Mats. One vector is one complete 4-byte element; component 0 is channel 0. Every signed value -128 .. 127 is preserved exactly. The Row/Column overloads require a 2-D Mat. The Index_Array overloads require one zero-based index per Mat dimension; iteration order maps to OpenCV dimension order regardless of the array's bounds. Depth must be exactly Int8 and the channel count exactly 4; violations raise OpenCV_Error.

Get

function Get (Image : Mat; Indices : Index_Array) return Int8_Vec4.Vector

Reads the complete element at a zero-based N-dimensional index. Indices'Length must equal Image.Dimension_Count. One vector is one complete four-channel element.

Parameters
Image

An Int8 Mat with exactly four channels and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Return Value

The four channel values of the element.

Raised exceptions
OpenCV_Error

Raised when Image is not an Int8 four-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.

Get

function Get (Image : Mat; Row, Column : Integer) return Int8_Vec4.Vector

Reads the complete element at a zero-based row and column of a two-dimensional Mat.

Parameters
Image

A two-dimensional Int8 Mat with exactly four channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Column

Zero-based column, in 0 .. Image.Columns - 1.

Return Value

The four channel values of the element.

Raised exceptions
OpenCV_Error

Raised when Image is not an Int8 four-channel two-dimensional Mat, or Row or Column is outside the Mat.

Set

procedure Set
  (Image : in out Mat; Indices : Index_Array; Value : Int8_Vec4.Vector)

Zero-based N-dimensional write of one complete four-channel element; the indexing rules of the matching Get apply. All four channels are stored together, in the Mat's actual storage, and are visible through every header sharing it.

Parameters
Image

An Int8 Mat with exactly four channels and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Value

The four channel values to store.

Raised exceptions
OpenCV_Error

Raised when Image is not an Int8 four-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.
