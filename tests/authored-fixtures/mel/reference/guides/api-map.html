API Map

Choose the family matching your task, then consult its generated package reference for exact types, preconditions and provider conditions. All 29 public library packages appear once in the directory below. A type or enum declaration does not establish an implemented runtime capability.

Select by developer task

Shared/Core

  • Establish the package namespace: AMS.
  • Load an IR provider, open a Session, inspect ABI/errors: AMS.MEL.
  • Interpret common health/status values: AMS.MEL.Status.

IR

  • Configure/start an image stream or retain legacy Mono8 Receive: AMS.MEL.IR.
  • Use common channel/capability values: AMS.MEL.IR.Channel.
  • Receive a full published frame representation or scoped pixel lease: AMS.MEL.IR.Image.
  • Poll the implemented Image metadata kinds: AMS.MEL.IR.Image.Metadata.
  • Send IR commands: AMS.MEL.IR.C2.
  • Use C2 KeepAlive, CommsTest and capability snapshots: AMS.MEL.IR.C2.Common.
  • Receive command/BIT metadata: AMS.MEL.IR.C2.Metadata.
  • Open Health/Status and consume metadata: AMS.MEL.IR.Health_Status and AMS.MEL.IR.Health_Status.Metadata.
  • Use conditional Instrumentation command/report support: AMS.MEL.IR.Instrumentation and AMS.MEL.IR.Instrumentation.Metadata.
  • Open conditional Track channels: AMS.MEL.IR.Track.
  • Receive the four implemented Track callbacks: AMS.MEL.IR.Track.Metadata.
  • Submit conditional Track updates: AMS.MEL.IR.Track.Updates.
  • Send optional SystemTrackDataResponse: AMS.MEL.IR.Track.System_Data.

RF

  • Open independent DataMEL and inspect MFA information: AMS.MEL.RF.
  • Receive RF integer samples or serialized AMS VITA packets: AMS.MEL.RF.Product_Rx.
  • Issue independent administration commands: AMS.MEL.RF.Admin.
  • Allocate apertures, request Jobs and control JobIntervals: AMS.MEL.RF.C2.
  • Inspect Element Group descriptors: AMS.MEL.RF.C2.Element_Groups.
  • Inspect DataPipes: AMS.MEL.RF.C2.Data_Pipes.
  • Observe optional JobInterval status: AMS.MEL.RF.C2.Interval_Status.
  • Observe coalesced VA change signals, without status snapshots: AMS.MEL.RF.C2.Virtual_Aperture_Notifications.
  • Query the VA definition ID, live VA status, VA instance status and required capability Booleans; obtain instance lists and copied instance-status reports: AMS.MEL.RF.C2.Virtual_Aperture_Queries. These are VA queries, not RF physical-data configuration.
  • Query conditional Local Function catalogs and status: AMS.MEL.RF.C2.Local_Functions. Local Function command configuration for JobIntervals belongs to AMS.MEL.RF.C2 itself, not this child query package.
  • Request conditional transmit-power calculations: AMS.MEL.RF.C2.Transmit_Power.

Required, conditional and represented-only

Core lifecycles and supported required command paths are implemented within their documented slices. Conditional families require runtime provider support: an interface existing in this reference does not force a provider to supply it. Capability enums preserve upstream vocabulary, including types without a corresponding bridge operation. Consult IR Workflows and RF Workflows before interpreting them.

The alias AMS.MEL.IR.Health_Status.Metadata.Status renames AMS.MEL.Status. GNATdoc omits this one source-visible package-renaming section; the target is linked above. It is not a thirtieth public library unit, a missing implementation, or an additional provider capability. The measured documentation result remains 4,294/4,295, not 100% of the complete inventory.

Package identities are derived from the public library-unit headers in ada/src. The portal resolves names against actual native h1 headings and reconciles them with docs/gnatdoc-native-anchors.json; authored guides never guess opaque page hashes.
