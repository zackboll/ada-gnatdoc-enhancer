Description

Outbound TrackDataUpdate under the upstream track-update condition, which is distinct from basic Track support. Requires Enabled Track. Positive execution is mock-qualified only; pinned Squall cannot attach Track. Bridge copies kinematics/covariance, performing no estimation, coordinate transformation, normalization or operational-incorporation verification.

Close

procedure Close (Request : in out Update_Request)

Idempotently close only the public observer; the Ada body ignores native close status. Provider work is not cancelled. Updates, system responses and common requests share Track accounting; only final pending completion permits deferred disable/detach, provider destruction and callback drain. Other pending work or unsafe-cleanup retention can keep the graph alive.

Parameters
Request

Observer to clear, externally serialized against Wait.

Submit

function Submit (Channel : Track_Channel; Value : Track_Data_Update) return Update_Request

Copy and send the update while Track is Enabled. Native lifecycle claim precedes unlocked provider send; no kinematic/score/covariance estimation or physical consistency validation is promised. Session admission refusal raises the resource-exhaustion exception; closed/ineligible channels, invalid text and other native/provider failures raise a provider error.

Parameters
Channel

Enabled Track owner; externally serialize owner operations.

Value

Complete update copied before Submit returns, including identity labels.

Return Value

Admitted observer, not confirmation of provider acceptance/incorporation.

Update_Request

type Update_Request is limited private;

Limited controlled update observer, distinct from system-response/common Ada owners. Native pending work independently retains the Track graph and Session admission permit. Finalization is non-raising; closure is not cancellation or direct release of a still-pending admission permit.

Update_Result

type Update_Result is private;

Owned terminal CommandStatus or explicit rejection. A successful outcome does not prove operational incorporation of kinematics by the provider.

Wait

function Wait (Request : Update_Request; Timeout_Milliseconds : Natural) return Update_Result

Wait for a terminal result, cached for repeat waits. Timeout raises the inherited timeout exception without consuming/cancelling. Explicit ErrorOr rejection is a result; provider/native/malformed-output failure raises a provider error. Deferred Track cleanup failure also fails the result closed and safely retains the graph rather than unloading uncertain provider code.

Parameters
Request

Open update observer; must not race Close.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Owned cached CommandStatus or explicit rejection.
