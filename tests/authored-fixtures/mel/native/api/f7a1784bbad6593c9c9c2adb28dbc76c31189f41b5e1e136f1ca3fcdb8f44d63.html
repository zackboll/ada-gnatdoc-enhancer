Description

Bounded owned polling of instrumentation report callbacks. Native callbacks validate and copy the four-field report into a drop-incoming queue without calling Ada. Receive returns independent Ada values. Upstream has no callback unregister operation; public consumption closure is distinct from physical provider-channel destruction.

Close

procedure Close (Stream : in out Metadata_Channel)

Idempotently deactivates public consumption and wakes native waiters. It does not unregister the provider callback, destroy the typed channel or promise immediate callback quiescence. Callback state remains until actual provider-channel destruction and bridge callback draining, which can be deferred by pending requests. Finalization attempts the same public consumption closure without raising.

Parameters
Stream

Public metadata owner to close; serialize against other uses.

Raised exceptions
Provider_Error

Native metadata cleanup failure.

Metadata_Channel

type Metadata_Channel is limited private;

Limited public metadata-consumption owner. Callback state belongs to the typed instrumentation channel, not this owner; finalization attempts non-raising consumption closure. Serialize operations on the same Ada object.

Metadata_Counters

type Metadata_Counters is record
   Events_Received, Events_Dropped_Queue_Full, Malformed_Or_Unsupported : Counter;
end record;

Saturating native callback counters, not counts of successful Ada receives.

Record fields
Events_Received

Observed callback entries, including entries after consumption becomes inactive.

Events_Dropped_Queue_Full

Valid incoming reports dropped when the bounded queue is full; queued reports are not evicted.

Malformed_Or_Unsupported

Null reports or unknown priority values rejected by callback validation; copying/allocation exceptions instead fail the metadata stream.

Open

function Open
  (Channel : Instrumentation_Channel; Queue_Capacity : Positive := 16) return Metadata_Channel

Registers the conditionally required report callback once per attached or enabled channel, including failed attempts. Provider registration can invoke the callback synchronously. A failed registration publishes no metadata owner but retains inactive callback state as required for safety; upstream provides no unregister operation. Queue ordering follows successful enqueue, not timestamps or concurrent callback entry order.

Parameters
Channel

Attached or enabled typed instrumentation owner.

Queue_Capacity

Maximum queued reports; defaults to sixteen.

Return Value

Limited public polling owner.

Raised exceptions
Provider_Error

Closed/ineligible channel, repeated registration, provider registration failure/exception or native failure.

Receive

function Receive
  (Stream : Metadata_Channel; Timeout_Milliseconds : Natural := 0) return Instrumentation_Report

Dequeues a complete native copied report, copies it into an Ada-owned record and closes the native temporary before return. No provider pointer escapes. Queued reports can drain after logical typed-channel closure or callback failure; an empty inactive queue raises Stream Stopped, and an empty failed queue raises Provider Error.

Parameters
Stream

Open polling owner; serialize Receive and Close on this object.

Timeout_Milliseconds

Maximum queue wait in milliseconds; zero polls.

Return Value

Independent report surviving metadata, channel and Session closure.

Raised exceptions
Timeout_Error

Active queue remained empty until the wait expired.

Stream_Stopped

Inactive or stopped queue is empty.

Provider_Error

Closed polling owner, failed callback state, invalid priority or native failure.
