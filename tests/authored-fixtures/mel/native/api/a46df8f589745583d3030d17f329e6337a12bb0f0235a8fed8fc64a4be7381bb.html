Description

Observe provider JobIntervalStatus callbacks without owning a JobDetail or any provider-resource graph. The callback receives status by value; its exact callable holder, bridge state and DSO pin remain for process lifetime because upstream provides no unregister or quiescence contract. Registration success is not evidence of callback delivery or scheduling. Serialize operations on an owner with that owner's destruction.

Open

function Open
  (Object                                       : Job;
   Queue_Capacity                               : Positive;
   Max_Event_Log_Entries, Max_Activity_ID_Bytes : Natural) return Stream

Attempt registration once on the Job, before Finalize or full Cancel. A synchronous callback during registration is supported. An exposed registration attempt is consumed even if the provider throws. The fixed FIFO drops incoming observations when full; malformed enums, oversize payloads and allocation failures discard whole observations. Limits bound queued storage, not provider argument construction, concurrent callback temporaries or application-held Status Event copies. Native option/lifecycle/registration failures raise Provider Error.

Parameters
Object

Live Job whose status is observed, not retained by Stream.

Queue_Capacity

Maximum number of queued observations; positive.

Max_Event_Log_Entries

Maximum entries per observation; zero allows only an empty log.

Max_Activity_ID_Bytes

Maximum activity bytes per observation; zero allows only an empty activity ID.

Return Value

Open observer; no delivery or physical RF activity is promised.

Receive_Event

function Receive_Event (Object : Stream; Timeout_Milliseconds : Natural) return Status_Event

Consume the next FIFO observation and copy it into Ada storage. Stop takes priority over queued data. Timeout Error means no observation arrived within the wait, not cancellation; Stream Stopped means stopped. Native failures or invalid native views raise Provider Error. Unknown callback enums are dropped natively, not returned as partial events.

Parameters
Object

Open local observer; may already be logically stopped.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Independent copied observation, including normal failure statuses.
