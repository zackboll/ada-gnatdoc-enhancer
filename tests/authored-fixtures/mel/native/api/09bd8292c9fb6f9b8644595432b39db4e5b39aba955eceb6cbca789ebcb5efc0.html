Description

Conditionally required IR MEL instrumentation support (upstream RequiredIfInstrumentation): typed attachment, recording-level commands and owned completion reports. The metadata child polls copied reports. Inherited common channel services are accessed through common Channel support. Only the published Normal and Debug recording levels are bound.

Close

procedure Close (Channel : in out Instrumentation_Channel)

Idempotently closes the typed public owner and deactivates metadata consumption. Pending requests defer physical disable/detach until completion. Cleanup disables if enable was attempted, detaches and destroys the provider channel before draining bridge callbacks. Synchronous detach failure retains the owner for retry; uncertain orphaned cleanup retains the provider graph. Automatic finalization attempts non-raising cleanup, not guaranteed immediate unload.

Parameters
Channel

Typed owner to close; serialize against other uses.

Raised exceptions
Provider_Error

Disable/detach or native cleanup failure; handle may remain for retry.

Close

procedure Close (Request : in out Instrumentation_Request)

Idempotently closes the public request handle without terminating provider work. Pending completion retains the native graph independently of public owners. Finalization attempts this cleanup without raising; the Ada wrapper ignores native close status. Do not race Wait on this same owner.

Parameters
Request

Public request owner to close.

Instrumentation_Channel

type Instrumentation_Channel is limited private;

Limited typed owner, initially closed. Open attaches without enabling. Native child state retains Session/provider lifetime after public Session closure. A common weak view does not keep this owner alive. Finalization attempts non-raising cleanup and can retain resources when detach ownership is uncertain. Externally serialize operations on a shared Ada owner.

Instrumentation_Config

type Instrumentation_Config is private;

Owned attachment configuration for the conditionally required instrumentation channel; constructing it performs no provider work.

Instrumentation_Report

type Instrumentation_Report is record
   Command_ID   : Interfaces.Unsigned_32;
   Size         : Interfaces.Unsigned_32;
   Timestamp_NS : Long_Long_Integer;
   Priority     : Instrumentation.Priority;
end record;

Canonical owned report used both for asynchronous command completion and metadata callbacks. The pinned declaration contains only these four fields, not a variable instrumentation-data payload.

Record fields
Command_ID

Provider report command identifier, preserving all 32 bits.

Size

Raw provider size field; the pinned header does not specify its units or relation to any payload length.

Timestamp_NS

Provider timestamp in nanoseconds; clock and epoch are unspecified.

Priority

Provider-reported Normal or Debug instrumentation level; unknown values fail conversion.

Instrumentation_Request

type Instrumentation_Request is limited private;

Limited public asynchronous-request owner. A private completion worker consumes the provider future once and caches the result while retaining the native channel, Session and provider code. Public request Close and finalization do not cancel provider work; a never-completing future can retain resources indefinitely. Finalization is non-raising.

Instrumentation_Result

type Instrumentation_Result is private;

Ada-owned terminal report or explicit rejection. Provider exceptions, null successful results, unknown priority/error values and native failures raise Provider Error rather than becoming a normal Rejected result. Values survive request closure.

Open

function Open (Parent : Session; Config : Instrumentation_Config) return Instrumentation_Channel

Attaches and verifies an InstrumentationChannel and its advertised instrumentation capability; no owner escapes on failure. This interface is conditionally required only for providers supporting instrumentation. Capabilities, common services and metadata registration are available while attached; instrumentation Submit requires explicit Enable. Native configuration text must be UTF-8 without embedded NUL. Failure cleanup retains the native graph if detach is uncertain.

Parameters
Parent

Open IR Session supplying the child provider channel.

Config

Complete typed attachment configuration.

Return Value

Attached, not yet enabled, limited channel owner.

Raised exceptions
Provider_Error

Closed Session, invalid text, provider attach/type/capability failure or native failure.

Enumeration Literal

Normal instrumentation recording level, upstream numeric value zero.

Debug

Debug instrumentation recording level, upstream numeric value one.

Submit

function Submit
  (Channel : Instrumentation_Channel; Command : Instrumentation_Level_Command)
   return Instrumentation_Request

Submits the supplied command only while the typed channel is enabled; does not implicitly Enable. Copies command values synchronously and returns a request handle, not proof of acceptance or completion. The native provider send runs outside the lifecycle lock so synchronous metadata callbacks can proceed. A pending request retains provider resources independently after public channel and Session closure.

Parameters
Channel

Enabled typed instrumentation owner; serialize application lifecycle operations.

Command

Command identifier and one of the two supported priority levels.

Return Value

Open limited request handle for later Wait.

Raised exceptions
Provider_Error

Closed/not-enabled channel, provider send exception or native failure.

Resource_Exhausted

Shared asynchronous-request admission limit reached.

Wait

function Wait
  (Request : Instrumentation_Request; Timeout_Milliseconds : Natural)
   return Instrumentation_Result

Waits for a terminal result without consuming the request. Timeout is not cancellation; later Wait may complete, and repeated terminal waits return the identical cached result. Explicit provider rejection is returned separately from provider exceptions or native failures. Rejection text is recovered completely by a checked cached retry if necessary; invalid UTF-8/NUL text receives a native fallback. Close must not race Wait on the same request.

Parameters
Request

Open public instrumentation request.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Owned report or explicit rejection.

Raised exceptions
Timeout_Error

Future has not completed within the wait; request remains open.

Provider_Error

Closed request, provider exception, invalid terminal result, or native/deferred-cleanup failure.
