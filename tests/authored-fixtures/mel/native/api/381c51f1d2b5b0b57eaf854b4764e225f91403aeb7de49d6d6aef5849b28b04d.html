Description

Safe Track attachment, lifecycle and complete inbound IRST report value. Positive Track behavior is mock-qualified only. Pinned Squall's Control attachment has no Track case and returns null; its real-provider evidence is an expected-negative unsupported path, not successful Track execution. Child packages separate inbound metadata from the two outbound sends. Serialize public operations and Close on a shared typed owner externally.

Close

procedure Close (Channel : in out Track_Channel)

Stop public admission and close the owner without cancelling futures. Physical disable/detach waits for all pending update, system-response and common requests. Disable is attempted if enabling was attempted; detach failure retains the graph/handle for retry. Disable failure can raise a provider error even after successful detach consumed the handle. Provider channel destruction, then callback-count drain, establishes quiescence; disable return alone does not. Orphaned unsafe cleanup retains resources.

Parameters
Channel

Track owner to close; serialize against its public operations.

Complete owned IRST report copied through native double fields without clamping, filtering, normalization or estimation. Pinned prose labels the filtered NED field as latest measurement too; the separate getter identity is retained rather than inventing a filtering algorithm. Positive report fidelity and callback behavior are mock-qualified, not Squall-qualified.

Open

Require an open Session and published Track capability, attach using the Track category and verify the concrete Track interface. Configuration text is validated natively. Failure raises a provider error; no owner escapes. Pinned Squall cannot attach this category. Positive behavior is mock-only.

Track_Channel

type Track_Channel is limited private;

Limited controlled owner of an attached provider Track channel, retaining the native Session graph independently of the parent Ada Session. Pending updates, system responses and common requests share native request counts and can retain resources after public closure. Finalization is non-raising.

Track_Config

type Track_Config is private;

Owned channel/platform UCI identities and sensor component location for an IRST Track attachment; creating a value performs no provider operation.
