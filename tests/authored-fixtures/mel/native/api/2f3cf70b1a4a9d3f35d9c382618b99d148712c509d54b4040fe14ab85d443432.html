Description

Owned inbound C2 command/BIT metadata and optional communications reports. Command status is independent of request Wait: accepting a command is not physical completion and the bridge supplies no additional correlation guarantee. All kinds share a bounded drop-incoming queue ordered by successful enqueue, not timestamps. Serialize stream operations and Close.

Close

procedure Close (Stream : in out Metadata_Stream)

Idempotently consume the public handle, mark an active queue inactive and wake waiters. This does not unregister callbacks, close C2, undo one-shot attempts or promise callback quiescence. Captured native state survives as needed; finalization closes without raising. Native failure raises a provider error. Serialize against all operations on this same stream.

Parameters
Stream

Metadata consumer to close, leaving copied events valid.

Enable_Comms_Test_Events

procedure Enable_Comms_Test_Events (Stream : in out Metadata_Stream)

Separately attempt communications-test callback registration once per C2 channel while Attached or Enabled. An expired channel, repeated attempt, provider refusal or exception raises a provider error. The attempt flag is set before registration, so failure is not retryable. No capability gate is applied and no other callback registration is undone. Native code checks channel lifecycle, not an additional queue-active condition; this operation does not revive an inactive consumer. A closed stream cannot be used.

Parameters
Stream

Open stream whose channel admits this first registration attempt.

Open

function Open
  (Channel : Control_Channel; Queue_Capacity : Positive := 16) return Metadata_Stream

Attempt one-shot registration in order: BIT configuration, command status, BIT status. No capability-advertisement gate or automatic communications registration is used here. Native code rejects a closed channel or prior metadata attempt; unlike sends it does not require Enabled. Partial failure leaves installed callbacks safely retaining inactive/failed queue state, marks the attempt consumed and raises a provider error; reopening is not a registration rollback. No partially open Ada stream escapes.

Parameters
Channel

Open typed C2 owner on which registration has not been attempted.

Queue_Capacity

Positive maximum queued events, default sixteen.

Return Value

Owned consumer for the three base callback families.

Receive

function Receive
  (Stream : Metadata_Stream; Timeout_Milliseconds : Natural := 0) return Metadata_Event

Pop the oldest successfully enqueued snapshot. Already queued events drain before stopped/failed state is reported. Empty active queue timeout raises the inherited timeout exception; stopped/inactive queue raises the inherited stopped-stream exception; native/callback terminal failure raises a provider error. Conversion validates enums and releases native event storage on exceptions.

Parameters
Stream

Open queue consumer, externally serialized against Close.

Timeout_Milliseconds

Maximum wait in milliseconds; default zero polls.

Return Value

Owned event of any enabled kind, independent of request Wait results.
