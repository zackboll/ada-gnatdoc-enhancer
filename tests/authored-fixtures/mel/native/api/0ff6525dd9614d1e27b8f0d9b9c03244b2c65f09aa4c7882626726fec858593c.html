Description

Owned polling of six HealthAndStatus metadata families and complete subsystem-health data. Shared status, BIT/fault and security types are authoritative in AMS.MEL.Status; the public Status renaming refers to that canonical package. GNATdoc 26 omits the renaming section, which remains an explicitly outstanding renderer exception. No optional NUC temperature callback is bound here.

Close

procedure Close (Stream : in out Metadata_Stream)

Idempotently closes public metadata consumption and wakes native waiters. It does not unregister callbacks or close the typed health channel. Callback state remains with the provider channel; channel destruction followed by bridge callback draining is the cleanup boundary, not public metadata Close. Finalization attempts cleanup without raising.

Parameters
Stream

Public metadata owner to close; serialize against other uses.

Raised exceptions
Provider_Error

Native metadata cleanup failure.

Open

function Open (Channel : Health_Channel; Queue_Capacity : Positive := 16) return Metadata_Stream

Registers the six bound health/status callbacks on an attached or enabled channel, once per channel including a failed attempt. Registration may synchronously produce events. Failure publishes no metadata owner; partial registrations retain inactive state because upstream has no unregister operation. All kinds share one bounded drop-incoming queue ordered by successful enqueue, not timestamps or simultaneous callback entry order.

Parameters
Channel

Attached or enabled owning typed health channel.

Queue_Capacity

Maximum queued events across all six kinds; defaults to sixteen.

Return Value

Limited owner of public metadata polling.

Raised exceptions
Provider_Error

Invalid/closed channel, repeated registration attempt, provider registration failure/exception or native failure.

Receive

function Receive
  (Stream : Metadata_Stream; Timeout_Milliseconds : Natural := 0) return Metadata_Event

Dequeues one native event, deeply copies its active payload to Ada and closes the temporary native event before returning. Existing queued events can drain after channel closure or callback failure; an empty inactive queue raises Stream Stopped, while an empty failed queue raises Provider Error. Provider callbacks never call Ada. Malformed records are discarded; exceptions during callback copying/allocation mark the metadata stream failed rather than being silently counted as a malformed record.

Parameters
Stream

Open public metadata owner; externally serialize use and Close.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Ada-owned discriminated event with independent nested data.

Raised exceptions
Timeout_Error

Active queue remained empty until the wait expired.

Stream_Stopped

Inactive or stopped queue is empty.

Provider_Error

Closed owner, failed callback state, invalid conversion or native failure.
