Description

Fresh explicit synchronous VA queries and Ada-owned snapshots. These operations are required upstream, including the capability Booleans; LF-specific conditional queries live in Local Functions. Separate calls have no atomicity or consistency guarantee and do not consume VA notifications. Query success is distinct from the returned status or False capability data.

Status_Kind

type Status_Kind is (None, Operational, Degraded, Failed);

Provider-reported VA or Local Function status, not transport success and not independent hardware qualification.

Enumeration Literal
None

No status reported.

Operational

Provider reports operational state.

Degraded

Provider reports degraded state.

Failed

Provider reports failed state; the query itself can still succeed.
