Description

Safe typed command-and-control channel and asynchronous command owners. Open attaches; Enable is explicit. Typed sends require Enabled, unlike inherited common operations which also admit Attached. Serialize owner operations externally. Native submission accounts lifetime under its lock and calls provider send unlocked; this is not permission to race public Ada owners. Future completion is not proof of a physical state transition or completed BIT; command-status metadata is a separate reporting path.

Close

procedure Close (Channel : in out Control_Channel)

Close public admission and consume the owner on success. Native disable/ detach is deferred while Mode, Return or Comms requests remain pending. Synchronous detach failure raises a provider error and retains the handle for retry. Disable failure can raise after successful detach consumed the handle; an orphaned deferred failure safely retains resources. Finalization is non-raising. Closing does not cancel provider futures.

Parameters
Channel

Owner to close; serialize against all its public operations.
