Description

Typed HealthAndStatus attachment, explicit enablement and common-channel integration. The child metadata package binds six health/status callback families using the canonical AMS.MEL.Status data types. This package does not duplicate inherited common channel services.

As_Channel

function As_Channel (Channel : Health_Channel) return IR.Channel.View

Creates a weak common Channel view while attached or enabled. Inherited KeepAlive, CommsTest and common capability services use common Channel support, not duplicated health methods. This view neither owns nor keeps the typed Health Channel alive; closing it does not close that owner.

Parameters
Channel

Live attached or enabled typed channel.

Return Value

New weak common channel view.

Raised exceptions
Provider_Error

Closed/failed owner or native view creation failure.

Close

procedure Close (Channel : in out Health_Channel)

Idempotently closes the typed public owner, deactivating metadata consumption. Native cleanup disables if enable was attempted and detaches before destroying the provider channel, then drains bridge callbacks. Pending inherited common requests can defer physical cleanup after logical Close. A synchronous detach failure retains ownership for retry; uncertain deferred failure deliberately retains the graph. Finalization attempts cleanup without raising and does not guarantee immediate unload. Closing a common view is not a substitute for closing this owner.

Parameters
Channel

Typed owner to close; do not race other operations on this owner.

Raised exceptions
Provider_Error

Disable/detach or native cleanup failure; a retained handle may require explicit cleanup retry.

Enable

procedure Enable (Channel : in out Health_Channel)

Explicitly enables the attached provider channel. Repeated Enable after success is a no-op; failure marks native lifecycle failed and requires cleanup rather than implying enabled service. Metadata may be registered before Enable.

Parameters
Channel

Attached owner to enable, or already enabled owner.

Raised exceptions

Health_Channel

type Health_Channel is limited private;

Limited typed owner, initially closed. Open attaches; Enable is explicit. Native state retains the Session/provider while this child needs it. Closing the public Session does not invalidate an existing channel. A weak common view does not keep this typed owner alive. Finalization attempts non-raising cleanup; failed detach can deliberately retain native resources for safety. Serialize lifecycle operations on the same Ada owner.

Health_Config

type Health_Config is private;

Owned configuration for attaching a typed HealthAndStatus channel; constructing it does not contact a provider.

Open

function Open (Parent : Session; Config : Health_Config) return Health_Channel

Attaches a HealthAndStatus channel, verifies its dynamic type and advertised channel capability, and publishes an owner only on success. Does not enable it. Metadata registration and capability queries are allowed while attached, before Enable. Native validation requires UTF-8 identity/location text without embedded NUL. Failed attachment/type validation attempts cleanup; uncertain detach retains the provider graph.

Parameters
Parent

Open IR Session whose provider supplies the child channel.

Config

Complete attachment identity and sensor location.

Return Value

Attached, not yet enabled, limited health-channel owner.

Raised exceptions
Provider_Error

Closed Session, invalid configuration text, provider attachment/capability/type failure or native failure.
