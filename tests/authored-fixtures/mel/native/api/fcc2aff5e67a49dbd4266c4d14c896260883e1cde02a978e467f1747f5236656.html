Description

IR foundation values and the legacy copied-frame image stream. This stream supports host-memory, single-band, eight-bit monochrome images; it performs no decoding, flipping, resampling or coordinate transforms. The richer image child package has separate full-header and frame-lease APIs; their capabilities must not be inferred for this legacy Frame.

Byte

subtype Byte is Interfaces.Unsigned_8;

Unsigned eight-bit octet used for UUID bytes and monochrome pixel storage.

Channel_View

type Channel_View is limited private;

Limited controlled owner of a weak common-channel view, used through the channel child package's View subtype. It owns only the view handle and never retains the typed channel, Session, provider objects or library. Keeping a view does not keep the resource it references open. Typed-family conversions and common operations enforce that resource's lifetime/state.

Close

procedure Close (Object : in out Image_Stream)

Release the public stream owner through native detach/cleanup. Repeated closure of a closed owner is harmless. Retained frames/requests or uncertain cleanup can retain the provider graph rather than unloading unsafe code.

Parameters
Object

Stream to close; do not race closure with Receive or other operations on this Ada owner.

Raised exceptions
Provider_Error

Native cleanup fails; explicit closure allows the caller to observe the failure instead of relying on finalization.

Component_Location

type Component_Location is private;

Host-system forward/right/down offsets in meters and an external key for the logical mounting location. No coordinate transformation is performed.

Frame

type Frame (Pixel_Count : Natural) is record
   System_Time_NS      : Long_Long_Integer;
   Integration_Time_NS : Long_Long_Integer;
   Width               : Interfaces.Unsigned_32;
   Height              : Interfaces.Unsigned_32;
   Bits_Per_Pixel      : Interfaces.Unsigned_32;
   Number_Of_Bands     : Interfaces.Unsigned_32;
   Horizontal_FOV_Rad  : Long_Float;
   Vertical_FOV_Rad    : Long_Float;
   Frame_ID            : Interfaces.Unsigned_32;
   Subframe_ID         : Interfaces.Unsigned_32;
   Subframe_Total      : Interfaces.Unsigned_32;
   Kind                : Image_Type;
   Flip                : Image_Flip;
   Image_Flags         : Interfaces.Unsigned_32;
   Dither_Row          : Long_Float;
   Dither_Column       : Long_Float;
   Row_Offset          : Interfaces.Unsigned_32;
   Column_Offset       : Interfaces.Unsigned_32;
   Band_Index          : Byte;
   Pixels              : Pixel_Array (1 .. Pixel_Count);
end record;

Ada-owned legacy Mono8 frame and selected scalar header metadata. Pixels are copied into this value and survive stream/session closure. This record does not expose the full header's contributing sensor or navigation arrays.

Record fields
Pixel_Count

Number of pixel octets owned by this frame; successful reception supplies width times height for single-band eight-bit data.

System_Time_NS

Provider image time in nanoseconds: integration start for staring images, first-line time for scanning/TDI images. No epoch conversion is performed by this wrapper.

Integration_Time_NS

Image integration duration in nanoseconds.

Width

Image width in pixels.

Height

Image height in pixels.

Bits_Per_Pixel

Eight for the supported legacy receive profile.

Number_Of_Bands

One for the supported legacy receive profile.

Horizontal_FOV_Rad

Horizontal field of view in radians.

Vertical_FOV_Rad

Vertical field of view in radians.

Frame_ID

Provider-assigned frame identifier.

Subframe_ID

Provider-assigned subframe identifier.

Subframe_Total

Total number of subframes in a frame, as reported.

Kind

Reported staring/scanning acquisition kind.

Flip

Reported flip configuration; pixels are not transformed.

Image_Flags

Bit set representing scan-first, scan-last, stare-snapshot and stare-rolling flags in native enum bit positions 0..3.

Dither_Row

Microscan row displacement: a positive value moves an object formerly at row Y to Y minus this displacement.

Dither_Column

Microscan column displacement: a positive value moves an object formerly at column X to X minus this displacement.

Row_Offset

Start-of-frame offset in rows in sensor coordinates.

Column_Offset

Start-of-frame offset in columns in sensor coordinates.

Band_Index

Provider band-map index identifying bands used for image.

Pixels

Owned one-based monochrome octets, with no decoding applied.

Image_Config

type Image_Config is private;

Ada-owned image-channel configuration copied into native storage on open. Buffer sizes/count and receive-queue capacity are bridge resource choices, not image transformations or promises of provider throughput.

Image_Flip

Reported image flip configuration; the bridge does not flip the pixels.

Enumeration Literal

Horizontal

A horizontal flip is indicated.

Both

Both vertical and horizontal flips are indicated.

Image_Stream

type Image_Stream is limited private;

Limited controlled owner of a legacy native image stream. Default state is closed. Explicit Close reports errors; finalization provides non-raising cleanup fallback. Native ownership retains provider/session state as needed independently of the parent Ada Session object's lifetime.

Image_Type

type Image_Type is (Staring, Scanning);

Provider-reported acquisition kind, not a requested image transformation.

Enumeration Literal
Staring

Image acquired by a staring sensor.

Scanning

Image acquired by a scanning sensor.

Pixel_Array

type Pixel_Array is array (Natural range <>) of Byte;

Unconstrained array of octets. Legacy received Frames own a one-based array of monochrome samples; borrowed views in child APIs have separate lifetime contracts and must not be treated as owned merely by this type.

Receive

function Receive (Object : Image_Stream; Timeout_Milliseconds : Natural := 0) return Frame

Receive a copied legacy frame using native size-discovery then copy calls. At most one task may call Receive on this stream at a time. Queued frames precede stopped/failure reporting. Serialize closure against this call.

Parameters
Object

Open legacy image stream whose next frame is consumed.

Timeout_Milliseconds

Wait duration in milliseconds; zero polls without waiting. A timeout neither stops the stream nor cancels provider work.

Return Value

Ada-owned pixels and selected scalar metadata for the next frame.

Raised exceptions
Timeout_Error

No frame becomes available within the wait.

Stream_Stopped

No queued frame remains and the stream is stopped.

Provider_Error

Closed/failed stream, size discovery failure or a frame outside this wrapper's Mono8 single-band metadata profile.

Stream_Counters

type Stream_Counters is record
   Frames_Received           : Counter;
   Frames_Dropped_Queue_Full : Counter;
   Malformed_Or_Unsupported  : Counter;
end record;

Snapshot of callback/rejection diagnostics, not successful Ada reads.

Record fields
Frames_Received

Incoming image callbacks counted before validation, including malformed data and queue-full drops.

Frames_Dropped_Queue_Full

Valid incoming frames rejected because the bounded receive queue has no space.

Malformed_Or_Unsupported

Malformed/unsupported callbacks and native callback failures rejected by the bridge, not timeout polls.

Stream_Stopped

Stream_Stopped : exception;

Receive found no queued frame and the native stream is stopped.

UCI_ID

type UCI_ID is private;

Ada-owned UUID and descriptive label. Predefined Ada equality compares both fields, including the label; matching UUID bytes alone need not make two Ada values equal. Pinned upstream equality also compares both fields.

UUID

type UUID is array (Natural range 0 .. 15) of Byte;

Exactly sixteen identifier bytes indexed zero through fifteen. These are binary identity bytes, not a UTF-8 label or a textual UUID encoding.
