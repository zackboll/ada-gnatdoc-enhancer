Description

Conditional VA-level connection snapshots and endpoint associations, separate from descriptor-level optional pipes. Values own their data and retain no provider lifetime. Each mutation obtains a fresh VA connection map and invokes the exact provider operation once, with no automatic capability gate, retry or readback. Externally serialize same-VA operations and Close; the existing VA owner remains valid after public C2 Close.

Associate_Endpoint

function Associate_Endpoint
  (Object                               : in out Virtual_Aperture'Class;
   Element_Group_Label, Data_Pipe_Label : String;
   Endpoint_ID                          : Interfaces.Unsigned_64) return Boolean

Obtain a fresh VA getDataPipes map, resolve existing exact keys, then invoke associateEndpoint exactly once. Missing keys are errors, never automatic insertions. No capability gate, retry, cache or state readback. Native/provider failures raise Provider Error. Provider acceptance does not establish actual connectivity, RDMA/Q-pairs, writable memory registration, hardware routing, persistent configuration or physical data delivery.

Parameters
Object

Live VA; externally serialize all same-VA operations, including Close. The existing VA claim survives public C2 closure.

Element_Group_Label

Exact outer lookup key; embedded NUL raises Constraint Error before native entry. Native code validates UTF-8.

Data_Pipe_Label

Exact inner lookup key, not returned display label. Embedded NUL raises Constraint Error; native code validates UTF-8.

Endpoint_ID

Exact unsigned 64-bit endpoint ID, without narrowing or local membership checks.

Return Value

True or False is successful provider return data, not transport status or a connectivity guarantee.

Connection_Snapshot

type Connection_Snapshot is private;

Ada-owned VA-level connection copy, distinct from optional ElementGroup descriptor pipes. Outer group keys ascend unsigned UTF-8 bytes without normalization or locale collation. Copies survive VA/C2 closure and provider unload.

Data_Pipe_Connection

type Data_Pipe_Connection is private;

Copied inner lookup key, distinct provider-returned label and associated endpoint set. Inner pipes preserve provider std::map traversal, including aliases.

Element_Group_Connection

type Element_Group_Connection is private;

Copied outer group lookup key and nested pipes, including successful empty groups. No native/provider ownership remains.

Snapshot

function Snapshot (Object : Virtual_Aperture'Class) return Connection_Snapshot

Make a fresh conditional VA getDataPipes call and copy labels and endpoint sets through temporary native snapshot ownership. Required upstream only with endpoint association. Invalid UTF-8, null pipes and native/provider failures raise Provider Error. No capability auto-gate or atomic multi-getter guarantee.

Parameters
Object

Live VA; externally serialize all same-VA operations, including Close. The existing VA claim survives public C2 closure.

Return Value

Independent VA connections, including successful empty collections.
