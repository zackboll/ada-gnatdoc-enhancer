Description

Observe signal-only callback entry, not live provider state. Register, query current status on the application thread, wait, then query again. Notifications contain no snapshot and do not guarantee changed state.

Close

procedure Close (Object : in out Subscription)

Stop and release only the local wrapper, idempotently, with no provider unsubscribe. VA Close performs its own registered-callback cleanup even after local Close. Controlled cleanup uses this non-raising local path.

Parameters
Object

Subscription to consume; do not race wrapper destruction.

Is_Open

function Is_Open (Object : Subscription) return Boolean

Inspect only local wrapper ownership, not provider registration status.

Parameters
Object

Subscription to inspect.

Return Value

True if the native local handle exists, even when stopped.

Open

function Open (VA : in out Virtual_Aperture'Class) return Subscription

Attempt one registration per VA; it may invoke the callback synchronously. Normal return proves registration returned, not later notification delivery. Provider/native failures raise Provider Error; no arbitrary retry follows an exposed registration attempt, even after local closure or unsubscribe.

Parameters
VA

Live VA; serialize registration with all same-VA operations.

Return Value

Local observer, not an owned provider-resource graph.

Statistics

function Statistics (Object : Subscription) return Subscription_Statistics

Copy all counters and flags under one native lock without consuming signals.

Parameters
Object

Subscription with a local handle, possibly stopped.

Return Value

Consistent signal statistics; no provider query or state guarantee.

Subscription

type Subscription is tagged limited private;

Limited local signal owner with non-raising controlled cleanup. The permanent callable/signal/DSO shell retains no VA or C2 owner. Its callback ignores the provider reference entirely and never dereferences it.

Subscription_Statistics

type Subscription_Statistics is record
   Callback_Entries        : Interfaces.Unsigned_64;
   Callbacks_Coalesced     : Interfaces.Unsigned_64;
   Notifications_Delivered : Interfaces.Unsigned_64;
   Callbacks_After_Stop    : Interfaces.Unsigned_64;
   Pending, Stopped        : Boolean;
end record;

Consistent nonconsuming bridge signal statistics; counters saturate at Unsigned 64'Last rather than wrapping. No provider state is included.

Record fields
Callback_Entries

All callable entries, including stopped entries.

Callbacks_Coalesced

Active entries arriving while already pending.

Notifications_Delivered

Successful waits consuming a pending signal.

Callbacks_After_Stop

Stopped callback entries counted and discarded.

Pending

An unconsumed coalesced signal exists, not a delivered snapshot.

Stopped

Reception has stopped; pending is cleared.

Subscription_Stopped

Subscription_Stopped : exception;

Wait observed logical stop; distinct from timeout or query status values.

Unsubscribe

procedure Unsubscribe (VA : in out Virtual_Aperture'Class; Object : in out Subscription)

Stop reception before attempting exact provider-key removal once. Cache the removal outcome, including failure; repeated calls do not retry. Provider failures raise Provider Error. Removal can block and provides no callback-quiescence guarantee; the callable shell remains permanent.

Parameters
VA

Matching live VA; serialize with same-VA operations and Close.

Object

Matching local subscription; remains locally open but stopped.

Wait_For_Change

procedure Wait_For_Change (Object : Subscription; Timeout_Milliseconds : Natural)

Consume one pending signal. Multiple callback entries coalesce into one pending notification; successful waits increment delivered, not entries. Stop clears pending and has priority. Raises Timeout Error on absence, Subscription Stopped on stop, and Provider Error for other native errors.

Parameters
Object

Open local subscription; no provider getter is called.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.
