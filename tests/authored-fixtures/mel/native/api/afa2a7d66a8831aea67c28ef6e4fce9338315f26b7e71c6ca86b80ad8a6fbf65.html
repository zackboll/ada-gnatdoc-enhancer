Description

Consumer-side MEL bridge foundation and IR provider-session ownership. The native facade ABI version is independent of provider API and library versions. Child packages expose only the implemented MEL service slices. Serialize operations on an owner against its closure; this package does not provide a task-safe lifetime protocol for a shared Ada Session.

type Async_Request_Limit is mod 2**32 with Size => 32;

Close

procedure Close (Object : in out Session)

Consume the public native handle; repeated closure is harmless. Releases this Session's shared ownership, not every child or request's ownership. The IR Control interface has no separate shutdown operation: object destruction and library unloading occur only when retained owners allow. This is not cancellation, a wait for all futures, or a quiescence promise.

Parameters
Object

Session to close; its handle is cleared by native closure. Serialize closure against other operations on this Ada owner.

Raised exceptions
Provider_Error

Native closure reports failure.

Open

function Open
  (Library_Path : String; Instance : String; Aperture_Config_ID : String := "") return Session

Load the provider, obtain its API manager and IR Control, and initialize the Control, using the default unlimited admission configuration. Strings are supplied as UTF-8 bytes without transcoding; this open path rejects embedded NUL but does not validate UTF-8. C++ ABI compatibility with the provider is still required behind the C facade.

Parameters
Library_Path

Provider shared-library path passed to the loader.

Instance

Provider instance passed to both factory functions.

Aperture_Config_ID

Configuration identifier passed to Control init; the empty default is supported and its meaning is provider-defined.

Return Value

Limited owner of the successfully initialized provider session.

Raised exceptions
Constraint_Error

Any input contains an embedded NUL; rejected before loading the provider.

Provider_Error

Loading, factory lookup, object acquisition or initialization fails, including a non-Success initialization result.

Open_With_Options

function Open_With_Options
  (Library_Path       : String;
   Instance           : String;
   Options            : Session_Options;
   Aperture_Config_ID : String := "") return Session

Open an IR Session with a copied asynchronous admission configuration. Loading, initialization and string handling are the same as Open. A bound limits bridge admission, not provider acceptance or completion time.

Parameters
Library_Path

Provider shared-library path passed to the loader.

Instance

Provider instance passed to both factory functions.

Options

Session-wide admission limit; zero is unlimited. Refused asynchronous submissions are not queued or retried.

Aperture_Config_ID

Configuration identifier passed to Control init; the empty default is supported and its meaning is provider-defined.

Return Value

Limited owner of the successfully initialized provider session.

Raised exceptions
Constraint_Error

Any input string contains an embedded NUL.

Provider_Error

Native loading, acquisition or initialization fails; a failed open does not return an open Session.

Provider_Error

Provider_Error : exception;

Native bridge or provider operation failure. This includes load, symbol, initialization and version-query failures; it is not a direct propagation of a C++ exception across the language boundary.

Provider_Version

type Provider_Version is private;

Ada-owned snapshot of provider API/library numbers and descriptive text. A default value has zero numbers and empty strings. Queried values remain usable after the Session closes; they contain no live provider reference.

Provider_Version_Number

type Provider_Version_Number is mod 2**32 with Size => 32;

Complete unsigned 32-bit provider version number, without bridge decoding into major/minor fields or substitution of the facade ABI version.

Query_Provider_Version

function Query_Provider_Version (Object : Session) return Provider_Version

Query Control version information and copy its numbers and complete text into Ada storage. Native validation requires UTF-8 text without NUL. The two-call size/copy protocol is not a provider version negotiation.

Parameters
Object

Open Session; serialize this query against Close.

Return Value

Independent snapshot with full 32-bit numbers and Ada-owned text.

Raised exceptions
Provider_Error

The Session is closed, the provider query fails, or the text is invalid or cannot be copied by the native protocol.

Program_Error

The native protocol reports a zero required string-buffer size.

Resource_Exhausted

Resource_Exhausted : exception;

Asynchronous submission refused by bridge admission before provider send. Distinct from a provider rejecting a command. Submission wrappers do not queue or retry a refused request.

Session

type Session is limited private;

Unique Ada owner of an initialized IR provider session. A default Session is closed. Explicit Close releases its native handle; controlled finalization is a non-raising cleanup fallback. Native child resources and outstanding requests can retain provider objects and code after closure. Neither closure nor finalization promises cancellation or physical completion of every asynchronous provider operation.

Session_Options

type Session_Options is record
   Max_Async_Requests : Async_Request_Limit := 0;
end record;

Admission configuration copied when a Session opens. It cannot be changed on that Session. A request timeout does not cancel provider work. Closing a request or waiting for it is not itself a capacity-release operation.

Record fields
Max_Async_Requests

Maximum admitted outstanding asynchronous work across the Session's participating channels; zero means unlimited.
