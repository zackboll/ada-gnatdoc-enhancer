Description

Historical C2-only access to inherited common Channel operations. The canonical common facade supports all five typed families through weak views; this compatibility child takes a typed C2 owner directly. Channel selectors and reports are shared with the common package, but the C2 Return owner/result and this child's Comms owner/result remain distinct Ada types. Handles cannot be substituted across these APIs. These are wrappers of existing upstream Channel services, not additional services. Serialize typed-owner operations externally and do not race request Close against Wait. Native pending work independently retains provider lifetime.

Capabilities

function Capabilities (Channel : Control_Channel) return IR.Channel.Channel_Capability

Query C2 capabilities while Attached or Enabled and copy them into the same owned value type as canonical common queries. Failed/closed lifecycle or native conversion failure raises a provider error. Metadata reports do not register callbacks or establish implemented Ada service support.

Parameters
Channel

Open C2 owner eligible for a capability query.

Return Value

Independent snapshot valid after channel, Session and provider closure.

Close

procedure Close (Request : in out Comms_Request)

Idempotently clear the public observer without cancelling its future. Pending native accounting and provider retention survive independently; unexpected native failure raises a provider error.

Parameters
Request

Legacy observer to close, externally serialized against Wait.

Comms_Request

type Comms_Request is limited private;

Legacy limited controlled communications-test observer, distinct from the canonical common request type despite sharing the native engine. Finalization closes without raising. Observer closure is not cancellation or direct release of a permit still held by pending native work.

Comms_Result

type Comms_Result is private;

Owned legacy communications-test terminal report or explicit rejection. Uses the parent's outcome/error types and the shared Channel report type, not the canonical common facade's distinct Ada result owner.

Send_Keep_Alive

function Send_Keep_Alive (Channel : Control_Channel) return Return_Request

Submit inherited keep-alive while C2 is Attached or Enabled, without implicitly enabling. Uses the shared native Return completion engine and Session admission pool. Exhaustion raises the resource-exhaustion exception; other native failures raise a provider error. Submission is not completion.

Parameters
Channel

Open eligible C2 owner; serialize its operations externally.

Return Value

C2 Return observer; use the parent package's Wait/Close and inspect payload separately from outcome.

Wait

function Wait (Request : Comms_Request; Timeout_Milliseconds : Natural) return Comms_Result

Await a terminal report/rejection through the shared native Comms engine. Results are cached for repeat waits. Timeout raises the inherited timeout exception without cancellation or consumption; other native failures raise a provider error. Long rejection text is retried and consistency checked. Unlike the canonical Ada wrapper, this legacy body directly converts the native rejection number; native enum mapping still rejects unknown codes.

Parameters
Request

Open legacy observer; must not race Close.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Owned legacy result, independent of later metadata callbacks.
