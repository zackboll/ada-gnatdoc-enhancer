Description

Conditional LF catalog and status queries, required upstream only when the MFA supports Local Functions. Each explicit snapshot makes a separate fresh provider call; snapshots can observe different states and imply no catalog/status membership or count consistency. Values retain no provider owner. These queries neither execute Local Functions nor perform register writes.

Snapshot_Local_Function_Status

   VA_Instance_ID         : Interfaces.Unsigned_32;
   Local_Function_Type_ID : Interfaces.Unsigned_32) return Status_List

Make one fresh conditional getLocalFunctionStatus call, independent of catalog and instance-report snapshots. No membership/count consistency check is performed. Unknown status enums or native/provider failures raise Provider Error; empty vectors succeed.

Parameters
Object

Live claimed VA; externally serialize with all same-VA calls, including Close.

VA_Instance_ID

Local_Function_Type_ID

Provider LF type ID passed unchanged; not validated against a cached catalog.

Return Value

Independent status vector in provider order; no register writes or LF execution performed.
