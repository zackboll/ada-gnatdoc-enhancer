Description

Complete-frame image access and asynchronous navigation over the consumer-side MEL bridge. Owned frames and explicit pixel copies have independent Ada storage; the lease path borrows provider host memory under an explicit limited owner. Only the documented Mono8 single-band receive subset is supported, not optional upstream image processing or pixel-format conversion.

Acquire_Frame

function Acquire_Frame
  (Object : AMS.MEL.IR.Image_Stream; Timeout_Milliseconds : Natural := 0) return Frame_Lease

Dequeues and owns one native snapshot, copying only small metadata and retaining the provider payload by address and length. Uses the same Mono8 single-band validated queue as owned Receive. At most one receive/acquire consumer may operate on a stream at once; independent acquired leases can be processed separately. Stream Stop/Close stops admission and can defer physical cleanup without invalidating held leases. Provider callbacks and navigation completion are synchronized internally, not permission for arbitrary concurrent operations on one Ada owner.

Parameters
Object

Image stream to consume; Start admits image callbacks.

Timeout_Milliseconds

Queue wait in milliseconds; zero is a nonblocking poll.

Return Value

Limited owner of one checked-out provider buffer and copied metadata.

Raised exceptions
Timeout_Error

No frame is available within the wait; does not stop the stream.

Stream_Stopped

Stream is logically stopped and no frame is available.

Provider_Error

Closed/failed stream, invalid converted metadata or payload span, or native failure.

Close

procedure Close (Frame : in out Frame_Lease)

Closes the lease and invalidates its borrowed payload, also on provider-release failure. An already-closed lease is a no-op. The retained buffer is returned through the published Buffer release operation when successful. Provider failure or exception makes ownership uncertain: the bridge deliberately retains the provider graph, exact buffer object and host memory to avoid unsafe reuse or unload. This is not successful buffer release; the failed release is not automatically retried. Explicit Close reports failure, whereas automatic finalization suppresses it and can retain resources for safety. Final-child closure may perform deferred channel cleanup. Do not race Close with a borrow, copy, or another operation on this same lease.

Parameters
Frame

Lease consumed by this operation; its payload count becomes zero.

Raised exceptions
Provider_Error

Native buffer release or deferred cleanup did not complete safely.

Close

procedure Close (Request : in out Navigation_Request)

Idempotently closes the public request handle without cancelling provider work. Pending completion independently retains the native graph, possibly beyond stream and Session closure. Finalization applies the same public-handle cleanup without raising. The Ada wrapper ignores native close status. Do not race this operation with Wait on the same request.

Parameters
Request

Public request owner to close.

Frame_Lease

type Frame_Lease is limited private;

Limited owner of one native snapshot retaining a provider-owned registered host buffer. The Frame Lease borrowed path performs no bulk image-payload copy from the MEL provider's registered host buffer into Ada. This is not end-to-end sensor zero-copy: pinned Squall copies UDP bytes into that host buffer; no DMA or kernel/network-stack zero-copy is claimed. Small metadata is copied at acquisition. A held lease keeps a provider buffer checked out; slow consumers cause backpressure or possible provider drops. Public stream/Session closure can be logical while physical teardown remains deferred behind leases, requests and release obligations. Closing the final child can trigger retained cleanup. Finalization is non-raising and can deliberately retain resources after uncertain release. Do not race lifecycle operations on a shared Ada object. Independent already-acquired leases may be processed separately; the stream still supports only one receive/acquire consumer.

Full_Frame

type Full_Frame is private;

Ada-owned complete frame snapshot: copied header, ordered flags, inertial/navigation sequences and pixel bytes. Unlike the smaller legacy IR Frame, this retains contributing-sensor identity and detailed navigation metadata. Returned snapshots survive stream, Session and provider closure.

Navigation_Request

type Navigation_Request is limited private;

Limited owner of a public asynchronous navigation request handle. A private completion worker consumes the provider future once and caches its terminal result. Pending work retains the underlying stream, Session and provider code after public Close. A future that never completes can retain those resources indefinitely. Finalization closes the public handle without raising; neither it nor explicit Close cancels provider work.

Receive

function Receive
  (Object : AMS.MEL.IR.Image_Stream; Timeout_Milliseconds : Natural := 0) return Full_Frame

Receives a complete frame by copying header metadata and the entire pixel payload into Ada-owned storage, then closing the temporary native snapshot before return. The result survives stream, Session and provider closure. Pixels makes another independent copy. This exposes more metadata than legacy IR Receive, but performs no pixel decoding or conversion. Only Mono8 single-band nonempty dimensions and validated host-buffer spans are accepted; malformed provider frames are discarded by the native callback. At most one receive/acquire consumer may use a stream at once. Externally serialize lifecycle operations on a shared Ada owner. Timeout does not stop the stream. The private snapshot cleanup helper ignores native release status; explicit lease Close is the reporting path for release failures.

Parameters

Timeout_Milliseconds

Maximum queue wait in milliseconds; zero polls without waiting.

Return Value

Complete independently owned frame and row-major payload bytes.

Raised exceptions
Timeout_Error

No frame became available within the wait.

Stream_Stopped

Stream has logically stopped with no frame available.

Provider_Error

Native/provider failure, closed stream, or invalid converted metadata/span.

Wait

function Wait
  (Request : Navigation_Request; Timeout_Milliseconds : Natural) return Navigation_Result

Waits for a cached terminal result without consuming the request. Timeout is not cancellation; later waits may obtain completion and repeated terminal waits return the cached result. Requires an open request in practice; closed handles and provider/native failures raise Provider Error. Public request Close must not race Wait. Cleanup failure after provider completion is reported as a failure rather than a false successful response. Rejection text is copied completely using a checked second cached read when needed; invalid UTF-8 or embedded NUL receives a native fallback description.

Parameters
Request

Open navigation request to observe.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Owned successful response or explicit provider rejection.

Raised exceptions
Timeout_Error

Request has not completed within the wait; remains open and pending.

Provider_Error

Closed request, provider exception, invalid result, or native/deferred-cleanup failure.

With_Pixels

procedure With_Pixels
  (Frame : Frame_Lease; Process : not null access procedure (Pixels : AMS.MEL.IR.Pixel_Array))

Synchronously invokes Process with a read-only-by-contract array aliasing native/provider storage, without a bulk payload copy. Array bounds are one through the byte count (one through zero if empty). The borrow ends when Process returns or raises: do not retain an address, slice, view or access object beyond that invocation. Keep the owning lease open throughout processing and do not race its Close. An exception from Process propagates without consuming the lease. Requires an open lease; enabled precondition checking raises Assertion Error on violation, while the body separately raises Provider Error for a closed handle or invalid payload address. No general thread safety or callback-quiescence guarantee is implied.

Parameters
Frame

Open owning lease which must remain open throughout Process.

Process

Synchronous read-only processor; must not retain any reference to borrowed storage.
