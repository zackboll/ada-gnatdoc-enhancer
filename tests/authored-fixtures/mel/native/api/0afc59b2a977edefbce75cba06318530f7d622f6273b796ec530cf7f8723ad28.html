Description

Owned polling of four image metadata callback families: bad pixels, line-of-sight report, line-of-sight Euler and navigation response. Optional LineOfSightQuaternion, OpticalDistortionMap and other upstream callbacks are not bound here. Payloads are copied at the native callback boundary and again into safe Ada values; no provider pointer is exposed.

Azimuth_Elevation

type Azimuth_Elevation is record
   Azimuth_Rad, Elevation_Rad : Long_Float;
end record;

Azimuth/elevation representation based on pinned AMS Math AzEl. Angle components are radians; the containing rate field must be distinguished from angles.

Record fields
Azimuth_Rad

Azimuth component; radians for an angle. The pointing-rate field has no explicitly documented time denominator upstream.

Elevation_Rad

Elevation component; radians for an angle. The pointing-rate field has no explicitly documented time denominator upstream.

Close

procedure Close (Stream : in out Metadata_Stream)

Idempotently closes public metadata consumption and wakes native waiters. Does not unregister provider callbacks, close the image stream, or guarantee immediate callback quiescence. Channel-owned callback state survives for safe later provider calls until channel destruction. Automatic finalization attempts cleanup without raising.

Parameters
Stream

Metadata owner to close; serialize against Receive and other uses.

Raised exceptions
Provider_Error

Native close failed.

Line_Of_Sight_Report

type Line_Of_Sight_Report is record
   System_Time_NS         : Long_Long_Integer;
   Pointing_Angle         : Azimuth_Elevation;
   Pointing_Angle_Rates   : Azimuth_Elevation;
   At_Speed               : Boolean;
   In_Tolerance           : Boolean;
   Platform_Attitude      : AMS.MEL.Status.Euler;
   Validity_Flag_Bitfield : Interfaces.Unsigned_32;
   Image_Rotation_Rad     : Long_Float;
end record;

Owned sensor pointing report copied without transformations. Validity bits are preserved but their positions are not defined by the pinned header.

Record fields
System_Time_NS

Provider system time in nanoseconds; clock and epoch are unspecified.

Pointing_Angle

Azimuth/elevation angles relative to the sensor, in radians.

Pointing_Angle_Rates

Provider pointing-rate components represented by AzEl; the pinned report does not explicitly establish rate units.

At_Speed

Provider indication that the MFA is at scan speed, subject to the validity field.

In_Tolerance

Provider indication that the MFA is within desired-position tolerance, subject to the validity field.

Platform_Attitude

Platform Euler attitude; consult the canonical Status Euler description and the validity field.

Validity_Flag_Bitfield

Raw validity value for at-speed, in-tolerance and platform-attitude fields; no bit positions are invented.

Image_Rotation_Rad

Provider image rotation in radians; no rotation is applied by the bridge.

Metadata_Counters

type Metadata_Counters is record
   Events_Received           : AMS.MEL.IR.Counter;
   Events_Dropped_Queue_Full : AMS.MEL.IR.Counter;
   Malformed_Or_Unsupported  : AMS.MEL.IR.Counter;
end record;

Saturating unsigned callback counters shared across the four kinds; these count callback activity, not successful Ada Receive calls.

Record fields
Events_Received

Callback entries observed, incremented even when consumption has become inactive.

Events_Dropped_Queue_Full

Valid copied incoming events discarded because the bounded queue is full; existing events are retained.

Malformed_Or_Unsupported

Null, unsupported or malformed events and copying/allocation failures rejected at the callback boundary.

Metadata_Event

type Metadata_Event is private;

Ada-owned tagged snapshot of one metadata event. Native temporary storage is closed before Receive returns; the value survives metadata stream, image stream and Session closure. No borrowed provider pointer escapes.

Metadata_Stream

type Metadata_Stream is limited private;

Limited owner of public metadata consumption. Callback state belongs to the image stream and can outlive this public owner. Close deactivates consumption, not provider callback unregistration; finalization attempts non-raising cleanup. Serialize operations on the same Ada owner.

Open

function Open
  (Stream : AMS.MEL.IR.Image_Stream; Queue_Capacity : Positive) return Metadata_Stream

Registers all four supported callbacks on an attached or running image stream, once per image stream, including after registration failure. Prefer registration before Start to avoid missing early events. A failed or unsupported registration raises Provider Error and publishes no metadata owner; already registered callbacks retain inactive state until provider-channel destruction because upstream supplies no unregister operation. All kinds share one bounded drop-incoming queue, ordered by successful enqueue under its mutex, not by timestamps or concurrent callback entry order. Closing metadata does not close the image stream.

Parameters
Stream

Owning image stream, not stopping, stopped or failed.

Queue_Capacity

Maximum number of queued events across all four kinds.

Return Value

Limited metadata-consumption owner.

Raised exceptions
Provider_Error

Closed/ineligible stream, repeated registration attempt, registration rejection/exception or native failure.

Receive

function Receive
  (Stream : Metadata_Stream; Timeout_Milliseconds : Natural := 0) return Metadata_Event

Dequeues one event and copies all active payload into Ada ownership before releasing its native temporary. Already queued events can drain after logical image Stop/Close; once empty, stopped consumption raises Stream Stopped. Provider callbacks never invoke Ada code. No automatic registration or optional callback binding is performed.

Parameters
Stream

Open metadata-consumption owner; externally serialize access and Close.

Timeout_Milliseconds

Maximum queue wait in milliseconds; zero polls.

Return Value

Independent owned event of one of the four supported kinds.

Raised exceptions
Timeout_Error

Active queue remained empty until the wait expired.

Stream_Stopped

Inactive or stopped queue is empty.

Provider_Error

Closed metadata owner, invalid converted event, or native operation failure.
