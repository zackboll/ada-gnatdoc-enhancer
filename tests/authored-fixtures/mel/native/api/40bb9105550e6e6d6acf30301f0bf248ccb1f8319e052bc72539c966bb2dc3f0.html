Description

Snapshots of required ElementGroup descriptors with optional conditional nested DataPipe acquisition. One explicit snapshot uses multiple provider getters, not an atomic transaction. Lookup keys and display labels remain distinct. Copied getters never access the provider; live acquisition requires external serialization with all same-VA operations, including Close.

Element_Group_Descriptor

type Element_Group_Descriptor is private;

Copied lookup key, provider display label, direction and numeric limits, with explicit nested-pipe inclusion state. No provider ownership remains.

Element_Group_List

type Element_Group_List is private;

Ada-owned descriptor collection sorted by unsigned UTF-8 lookup-key bytes. No text normalization or locale collation; no native handle, Close or provider-aware finalizer. Copies survive VA/C2/provider closure.

Snapshot_Element_Groups

function Snapshot_Element_Groups
  (Object : Virtual_Aperture'Class; Include_Data_Pipes : Boolean := False)
   return Element_Group_List

Obtain required getElementGroups and multiple descriptor getters, optionally acquiring conditional descriptor DataPipes and their labels/endpoints. This is not an atomic multi-getter transaction. Native snapshot storage is copied to Ada then released. Invalid UTF-8, null provider objects, unknown modes and native/provider failures raise Provider Error; no partial snapshot is returned.

Parameters
Object

Live VA; externally serialize all same-VA operations, including Close. The existing VA claim survives public C2 closure.

Include_Data_Pipes

If True, query nested descriptor pipes. False means not queried, not absent or unsupported; an included empty map is different.

Return Value

Independent sorted descriptors; successful empty collections are retained.
