Description

Four inbound callback families, not outbound RequestFor sends. Required Track reports, advertised candidate messages and two optional callbacks share one bounded drop-incoming FIFO ordered by successful enqueue, not provider timestamps. Native callbacks never invoke Ada. Positive behavior is mock-qualified; pinned Squall cannot attach this Track channel.

Background_Index

subtype Background_Index is Positive range 1 .. 3;

One-based row/column index into the exact three-by-three background patch, not a provider image coordinate.

Candidate_Background

type Candidate_Background is array (Background_Index, Background_Index) of Interfaces.Integer_16;

Owned 3x3 signed 16-bit intensity patch around a candidate. Native row-major nine-sample storage is mapped explicitly to Ada row/column indices; signed values survive without unsigned conversion or intensity rescaling.

Candidate_Object_Header

type Candidate_Object_Header is record
   Number_Of_COs          : Interfaces.Unsigned_16;
   Stack_Frame_Index      : Interfaces.Unsigned_16;
   CFAR                   : Float;
   Validity_Flag_Bitfield : Interfaces.Unsigned_16;
   TOV_UTC_NS             : Long_Long_Integer;
end record;

Owned fixed header fields; variable hot regions are accessed through the message. Count meaning differs between fixed-array and PreProc messages.

Record fields
Number_Of_COs

Declared unsigned 16-bit candidate count; fixed-array messages use this prefix, PreProc vectors have an independent length.

Stack_Frame_Index

Zero-based current frame index within a stack sequence.

CFAR

Upstream binary32 average per-pixel false alarm rate, FA/pixel; retained as Float without widening or algorithm inference.

Validity_Flag_Bitfield

Opaque unsigned 16-bit validity for stack index/CFAR; bit definitions are not invented.

TOV_UTC_NS

Signed UTC-named time-of-validity nanosecond count; no more specific epoch is established.

Candidate_Object_Message

type Candidate_Object_Message is private;

Owned header, navigation, hot regions and candidate prefix. Upstream fixed capacity is 900; declared count greater than capacity is malformed. Only the meaningful prefix is copied, in native order, retaining duplicates.

Open

function Open (Channel : Track_Channel; Queue_Capacity : Positive := 16) return Metadata_Channel

Register once while Attached or Enabled, without the Track lifecycle lock held across provider registration. Order: required Track report; candidate message only if advertised at Track Open; optional system-data request; optional candidate PreProc. Required report refusal and advertised candidate refusal fail, including NotSupported. Optional callbacks accept NotSupported non-fatally but other non-Success answers fail. Partial failure consumes the attempt and retains inactive/failed callback state without unregister; no public consumer escapes. Reopening after Close does not retry registration.

Parameters
Channel

Open Attached/Enabled Track owner; serialize owner operations.

Queue_Capacity

Positive shared queue bound, default sixteen events.

Return Value

Owned queue consumer; registration failure raises a provider error.

Receive_Event

function Receive_Event
  (Stream : Metadata_Channel; Timeout_Milliseconds : Natural := 0) return Metadata_Event

Pop the oldest successfully enqueued event of any supported kind. Queued values drain before stopped/failed state is reported. Empty active timeout raises the inherited timeout exception; stopped/inactive raises the inherited stopped-stream exception; native/callback/conversion failure raises a provider error. Native storage is released on copying exceptions.

Parameters
Stream

Open metadata consumer, externally serialized against Close.

Timeout_Milliseconds

Maximum wait in milliseconds; default zero polls.

Return Value

Wholly Ada-owned discriminated event with no surviving provider references.
