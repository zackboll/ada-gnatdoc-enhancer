Description

Shared channel capability snapshots and the weak common-channel facade. Capability values describe provider reports, not a promise that the Ada bridge implements every advertised operation. Reading metadata support does not register a callback. Snapshots own their strings and collections independently of the provider, Session and typed channel.

Capabilities

function Capabilities (Channel : View) return Channel_Capability

Temporarily lock the weak target and apply its typed capability lifecycle check, then copy the report into Ada-owned storage. Closed/expired views and provider/native failures raise a provider error. Local handle presence alone proves neither target existence nor eligibility. Reading this report registers no callbacks and does not implement advertised services.

Parameters
Channel

Open weak view whose typed resource admits capability queries.

Return Value

Owned snapshot valid after view, typed owner, Session and provider closure.
