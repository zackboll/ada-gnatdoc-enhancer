Description

Asynchronous RF receive creation and bounded delivery of copied callback products. The eight supported integer/VITA formats use native v9 metadata; no DSP, RDMA setup, physical reception or provider-wide callback quiescence is promised. Limited owners require explicit Close, with non-raising finalization fallback.

Assigned_Data_Format

function Assigned_Data_Format (Object : Endpoint) return Job_Data_Format

Read the cached assigned provider format. Creation checks equality with the requested supported format before callback registration.

Parameters
Object

Endpoint containing the cached format, which remains stored after Close.

Return Value

One of formats 0 through 7 after successful Claim; no conversion or broader upstream support is implied.

Claim

function Claim (Request : Create_Request'Class) return Endpoint

Transfer successful unclaimed creation to exactly one endpoint and register its data-ready callback. Pending Claim raises Timeout Error; failed, already-claimed or registration-failed requests raise Provider Error. A registration failure is cached and is not retried. Callback state is ready before registration, allowing synchronous callbacks. The exact registered std::function lvalue, callback state and provider DSO remain permanently retained: providers may keep a reference or move the callable. This shell owns neither DataMEL nor endpoint nor event payloads.

Parameters
Request

Open successful request; only one Claim may succeed.

Return Value

Unique open endpoint with the requested format verified against the assigned format; not proof of reception.

Close

procedure Close (Request : in out Create_Request)

Idempotently abandon the public request without cancelling the future. A pending worker retains the provider graph until settlement; an abandoned successful unclaimed endpoint is destroyed without callback registration. A claimed endpoint remains independently owned. Explicit closure reports native failures; automatic finalization is non-raising.

Parameters
Request

Owner consumed by closure; do not race its destruction with Wait or Claim.

Close

procedure Close (Object : in out Endpoint)

Idempotently consume the endpoint owner. Native logical closure discards queued products and wakes receivers before draining admitted bridge callback bodies; only then is the provider endpoint destroyed and its parent claim released. This drain is not provider-wide callback quiescence. Late callbacks take the stopped path before payload access. The permanent callable/state/DSO shell is not freed at Close. Failure to establish safe drain retains endpoint and claim; throwing parent shutdown permanently retains its provider graph. Delivered Events remain usable.

Parameters
Object

Endpoint owner to close; externally serialize wrapper destruction against other operations. Explicit failures raise Provider Error; finalization does not propagate them.

Close

procedure Close (Value : in out Event)

Idempotently release the sole native copied event and clear borrowed sample/packet addresses and count. Cached ID, format and Ada metadata remain stored; previously returned metadata and explicit payload copies remain independent. Externally serialize all event access with closure. Automatic finalization attempts the same release without propagating exceptions.

Parameters
Value

Event owner consumed; no provider sample buffer or endpoint is destroyed here.

Config

type Config is private;

Copyable request settings, not a provider resource. Formats are Direct INT8 (0), Direct INT16 (1), Complex INT8 (2), Complex INT16 (3), and AMS VITA Small/Medium/Large/Extra Large (4 through 7). Constructors only store settings; Submit checks the native domain, positive queue/maximum and region representability before provider entry. No PDW or Local Function receive alternative is supported.

Counter

type Counter is mod 2**64 with Size => 64;

Unsigned 64-bit diagnostic count. Native increments saturate at the maximum rather than wrapping, despite the modular Ada representation.

Counters

type Counters is record
   Callbacks_Received          : Counter;
   Products_Queued             : Counter;
   Products_Dropped_Queue_Full : Counter;
   Malformed_Or_Unsupported    : Counter;
   Allocation_Failures         : Counter;
   Callbacks_After_Close       : Counter;
end record;

Consistent copied native queue/callback counters; these are bridge observations, not RF performance measurements.

Record fields
Callbacks_Received

All bridge callback entries, including late callbacks after logical closure.

Products_Queued

Complete products successfully appended to the queue; cumulative, not current queue depth.

Products_Dropped_Queue_Full

Incoming complete products discarded because the bounded queue was full; older queued products remain.

Malformed_Or_Unsupported

Callbacks rejected for invalid metadata, wrong alternatives, oversize counts or unsupported content; no partial product is queued.

Allocation_Failures

Callback copy or queue-allocation failures; no partial event is published.

Callbacks_After_Close

Entries observed after logical Close, or admitted copies that lost publication to Close.

Normal terminal creation outcome, distinct from timeout and bridge/provider exceptions.

Enumeration Literal
Created

Create_Request

type Create_Request is tagged limited private;

Unique limited controlled owner of an asynchronous creation completion. Default initialization is closed. Native ownership retains DataMEL and its library across pending future, cached success and unique endpoint Claim; no reference to the parent Ada object is needed. Close abandons ownership, not provider work. Finalization attempts closure without raising.

Create_Result

type Create_Result is private;

Ordinary copied terminal result, independent of request lifetime. Created and Failed are normal outcomes; timeout and provider/bridge exceptions are raised instead. Failure text is copied, with a fallback for invalid provider UTF-8; unknown rejection codes and null/mismatched endpoints are diagnosed rather than accepted.

Unique limited controlled owner of one immutable native copied callback product, plus ordinary Ada metadata copies. Default initialization is closed. type Product_Metadata is private;

Safe Ada Submit and Receive use native v9 for all formats 0..7, adding stabilization to v8 association semantics; these profile numbers are not new formats.
