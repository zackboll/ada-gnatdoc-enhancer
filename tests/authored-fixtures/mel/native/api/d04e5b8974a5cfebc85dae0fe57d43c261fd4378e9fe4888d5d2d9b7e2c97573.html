Description

Ada-owned Common MEL status values for built-in tests, faults, component health and security audit data. Constructors copy their inputs; they do not query a provider or enforce a provider's state machine. Returned text and nested values are copies, not borrowed native storage. Collection access uses Positive indices starting at one; an index beyond the stored length fails an Ada constraint check. Appending preserves order and duplicates.

BIT_Control_Interface

type BIT_Control_Interface is
  (Not_Set, Subsystem_BIT_Command, Subsystem_State_Command, Subsystem_Initiated);

Provider-reported BIT control-interface identifier, preserving the pinned numeric mapping. Values two and three have contradictory upstream prose; they must not be used to infer whether a BIT changes subsystem state.

Enumeration Literal
Not_Set

No control-interface value has been set.

Subsystem_BIT_Command

Interface value one: manual/initiated BIT via a BIT command, described upstream as interleavable with operational work.

Subsystem_State_Command

Interface value two, named state command. Pinned prose instead describes self-initiated BIT; behavior is unresolved.

Subsystem_Initiated

Interface value three, named subsystem initiated. Pinned prose instead describes a state-command transition to initiated BIT; the bridge preserves the value without resolving that ambiguity.

Category

function Category (Value : Security_Event) return Natural

Read the kind-specific category number. Zero is unset for each concrete upstream subtype. Authentication values 1..7 mean subsystem, service, configuration-file, operational-software, mission-data-file, other-file and other-device authentication. Integrity 1..6 means configuration, bootloader, operational-software, mission-data-file, other-file and other integrity checks. File management 1..4 means configuration, operational- software, mission-data-file and other-file updates. Key management 1..6 means key load, generation, update, deletion, certificate load and deletion. System 1..4 means startup, shutdown, reset and fault. Sanitization 1..3 means zeroization, sanitization and classified-data erase.

Parameters
Value

Event whose kind selects the numeric category vocabulary.

Return Value

Stored category without decoding; Ada-created values need not lie in a native subtype's supported category range.

  (Not_Set, Unknown, Not_Installed, Off, Initializing, Operational, Degraded, Disabled, Faulted);

Capability-related state of one subsystem component, not overall MFA state.

Enumeration Literal
Not_Set

No component-state value has been set.

Unknown

The component's state is unknown.

Not_Installed

Off

Installed but not powered on.
