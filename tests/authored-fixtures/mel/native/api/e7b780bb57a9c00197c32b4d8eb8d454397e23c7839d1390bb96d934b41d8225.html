Description

Optional outbound system Track data response, distinct from inbound system-data-request metadata. Requires Enabled Track; no automatic response or physical incorporation guarantee is supplied. Positive qualification is mock-only; pinned Squall cannot attach the Track channel. Request lifetime and admission are shared natively with updates and common Channel requests.

Response_Request

type Response_Request is limited private;

Limited controlled response observer, distinct from update/common owners. A pending native worker independently retains Track/Session/provider graph and Session admission permit. Observer closure is not cancellation or direct pending-permit release; finalization closes without raising.

Submit

function Submit
  (Channel : Track_Channel; Value : System_Track_Data_Response) return Response_Request

Copy and submit the optional response while Track is Enabled. Native accounting precedes unlocked provider send. Attached-only/failed/closed resources and native/provider failures raise a provider error; Session-wide admission refusal raises the resource-exhaustion exception. No field is zeroed based on validity flags and no physical validation is promised.

Parameters

Enabled Track owner; externally serialize its public operations.

Value

Complete response payload copied before submission returns.

Return Value

Admitted observer, not provider acceptance or operational incorporation.

Wait

function Wait
  (Request : Response_Request; Timeout_Milliseconds : Natural) return Response_Result

Await or repeat a cached terminal result. Timeout raises the inherited timeout exception without consumption/cancellation. Explicit ErrorOr rejection returns a result; provider/native failure raises a provider error. Malformed status and deferred Track cleanup failure also raise that error; failed deferred cleanup safely retains resources instead of unloading code.

Parameters
Request

Open response observer; must not race its Close.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Owned cached terminal payload or explicit rejection.
