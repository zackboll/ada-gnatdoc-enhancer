Description

RF DataMEL ownership and copied MFA, face, installation and transmit-power characteristics. This provider family is independent of an IR Session. Capability reports do not demonstrate active RF transmission or real hardware qualification. Child packages provide separately scoped services. Serialize operations on one DataMEL owner against each other and Close. Snapshot values contain no live provider reference and may outlive it.

Close

procedure Close (Object : in out Data_MEL)

Consume the public owner; closing an already closed owner is harmless. Native shutdown is deferred while asynchronous create-request/endpoint children retain claims. Otherwise shutdown precedes provider destruction. Throwing shutdown retains the provider graph rather than unloading unsafe code; registered callback code can also remain retained for process life. This is neither cancellation nor destruction of all independent children.

Parameters
Object

Owner to close; serialize against operations on this object.

Raised exceptions
Provider_Error

Native cleanup or immediate shutdown fails; the public handle is consumed even when shutdown reports failure.

function Open (Library_Path : String; Configuration : String) return Data_MEL

Load a provider library and call its RF DataMEL factory, not IR factories. Strings are passed as UTF-8 bytes without transcoding; this open path does not validate UTF-8. Compatible provider C++ ABI remains required behind the facade.

Parameters
Library_Path

Shared-library path containing the RF factory.

Configuration

Text passed to the provider factory; its syntax and interpretation are provider-defined, not a bridge configuration schema.

Return Value

Limited owner of the acquired RF DataMEL.

Raised exceptions
Constraint_Error

Either input contains an embedded NUL, rejected before loading the provider.

Provider_Error
