Description

Four independent conditional provider calculations, required upstream only if the associated MFA supports transmit. No local calculation or automatic capability gate is supplied. A successful numeric result is provider data, not proof of physical RF activity. Calls require an existing live VA and same-VA external serialization, including Close; the public C2 may already be closed.

Aperture_Gain_DB

function Aperture_Gain_DB
  (Object              : Virtual_Aperture'Class;
   Element_Group       : Element_Group_ID;
   Power_Mode_ID       : Interfaces.Unsigned_32;
   Weight_Type         : Weight_Type_ID;
   Center_Frequency_Hz : Long_Float;
   Line_Of_Sight       : UV_Line_Of_Sight;
   VA_Instance_ID      : Interfaces.Unsigned_32 := 0) return Long_Float

Invoke conditional RequiredIfTransmit getTxApertureGain exactly once. No automatic capability gate, RF formula, caching, interpolation or reconciliation with separately queried values. Inputs/results preserve floating-point semantic values, including signed zero, infinity and NaN classification, without finite/range enforcement; no NaN payload- bit guarantee. Native/provider failures raise Provider Error. A returned number does not prove transmission, emission, antenna performance or valid hardware state.

Parameters
Object

Live claimed VA; externally serialize with all same-VA calls, including Close. Its existing native claim remains usable after public C2 Close.

Element_Group

Provider numeric transmit-group ID; must fit native size t.

Power_Mode_ID

Provider power-mode ID, distinct from attenuation and weight type.

Weight_Type

Provider weight-type ID fitting native size t; no Weights owner is allocated.

Center_Frequency_Hz

Center frequency in Hz, without unit conversion or interpolation.

Line_Of_Sight

U/V components passed verbatim as an AnglePair, not normalized.

VA_Instance_ID

Provider-defined VA instance selection, default 0; no local membership check.

Return Value

Provider transmit aperture gain in dB; no inferred relationship to other query results.

Element_Group_ID

subtype Element_Group_ID is Interfaces.Unsigned_64;

Unsigned provider transmit element-group ID, not a label. Native size t representability is checked before provider entry; failure raises Provider Error without truncation.
