# Actual Core documentation search regression

These are the complete 195 public package/native page pairs and five published
developer guides from the retained GNATDOC-019 qualification, also exercised by
the v0.1.2 release qualification (GNATDOC-021). Declaration HTML and Ada sources
are not synthesized, shortened, or rewritten. The public source selection,
native bytes, authored guide inputs, and generic qualification remain bound by
their existing qualification records. `oracle.json` retains the independently
source/native-bound declaration destinations and source-order overload numbers.

`provenance.json` additionally binds every fixture byte. The only configuration
adaptation is adding the existing, hash-approved Core custom theme from
`opencv_core_ada` revision `33a2a4f3b83606a5c779b8a93abeb6c91fa49a21` to the two
qualification configurations. No consumer configuration is changed. Search is
enabled only on disposable test copies. Upstream copyright and Apache-2.0
licensing remain unchanged.

The fixture proves static search and navigation against actual GNATdoc 26
output; it does not certify a new GNATdoc build, Ada compilation, or consumer
migration. The full-site compatibility harness separately regenerates retained
Core, Geometry, Imgproc, and MEL publications.
