Description

Whole-row access to three-channel UInt16 (CV_16UC3) two-dimensional Mats, by copy (Read_Row, Write_Row) or by a zero-copy callback-scoped view (With_Read_Only_Row, With_Writable_Row). Each array element is one complete three-channel pixel. Row and column indices are zero-based. Every operation validates the Mat's depth, channel count, row index and row length and raises OpenCV_Error on any mismatch.

Read_Row

procedure Read_Row (Image : Mat; Row : Natural; Data : out Row_Array)

Copies one row of Image into Data. Data'Length must equal Image.Columns; Data (Data'First) receives column 0. Image is unchanged and Data owns its values.

Parameters
Image

A two-dimensional UInt16 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Data

Receives one three-channel pixel per column.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt16 three-channel Mat, Row is outside the Mat, or Data'Length differs from Image.Columns. Also raised when Data'Length exceeds Natural'Last / 3: copied rows use an intermediate buffer of three scalar channels per vector. This limit does not apply to the zero-copy row callbacks.

Row_Array

type Row_Array is array (Natural range <>) of UInt16_Vec3.Vector;

The values of one Mat row, one UInt16_Vec3.Vector per column. Only the length matters: the first array element corresponds to column 0.

With_Read_Only_Row

procedure With_Read_Only_Row
  (Image   : Mat;
   Row     : Natural;
   Process : not null access procedure (Data : aliased Row_Array))

Callback-scoped, zero-copy row access with a shallow storage lease. Data aliases the native storage of that row (one complete three-channel pixel per element) and is valid only during Process.

Parameters
Image

A two-dimensional UInt16 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Process

Callback that receives the borrowed row. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a two-dimensional UInt16 three-channel Mat or Row is outside the Mat.

With_Writable_Row

procedure With_Writable_Row
  (Image   : in out Mat;
   Row     : Natural;
   Process : not null access procedure (Data : aliased in out Row_Array))

As With_Read_Only_Row, except Process receives an in-out view whose writes mutate the actual Mat storage immediately.

Parameters
Image

A two-dimensional UInt16 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Process

Callback that receives the borrowed row for reading and writing. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a two-dimensional UInt16 three-channel Mat or Row is outside the Mat.

Write_Row

procedure Write_Row (Image : in out Mat; Row : Natural; Data : Row_Array)

Copies Data into one row of Image. Data'Length must equal Image.Columns; Data (Data'First) is stored in column 0. The values are written to the Mat's actual storage, so shallow aliases and the parent of a Region observe them.

Parameters
Image

A two-dimensional UInt16 Mat with exactly three channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Data

One three-channel pixel per column.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt16 three-channel Mat, Row is outside the Mat, or Data'Length differs from Image.Columns. Also raised when Data'Length exceeds Natural'Last / 3: copied rows use an intermediate buffer of three scalar channels per vector. This limit does not apply to the zero-copy row callbacks.
