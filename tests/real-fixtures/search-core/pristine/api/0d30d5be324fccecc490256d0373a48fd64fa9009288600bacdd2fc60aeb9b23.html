Description

Callback-scoped CV_8SC2 Mat headers over caller-owned Data. One Data entry is one complete 2-byte C2 element; each component is a signed -128 .. 127 value. Packed views require Data'Length = Rows * Columns or product (Shape). Strides count complete Int8_Vec2 elements, not scalar Int8 channels or bytes; the final N-D stride is 1 and padding is never touched. No data is copied and the caller retains ownership. The Mat is valid only during Process: shallow copies, Region, Slice and Reshape are rejected; Clone is the independent escape path. Components 0 and 1 are OpenCV channels 0 and 1; no semantic channel meaning is assigned.

Buffer_Array

type Buffer_Array is array (Natural range <>) of Int8_Vec2.Vector;

A flat buffer of complete two-channel vectors supplied by the caller. Only Data'First and Data'Length are used.

With_Read_Only_Mat_View

procedure With_Read_Only_Mat_View
  (Data    : aliased Buffer_Array;
   Shape   : Dimension_Array;
   Process : not null access procedure (Image : Mat))

Read-only view of a packed N-dimensional buffer; the geometry rules match the writable Shape overload.

Parameters
Data

The caller-owned packed buffer that Image aliases; it may be an aliased constant.

Shape

Extent of each dimension, in OpenCV dimension order.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape is invalid, has more dimensions than the linked OpenCV supports, or Data'Length differs from the product of Shape.

With_Read_Only_Strided_Mat_View

procedure With_Read_Only_Strided_Mat_View
  (Data    : aliased Buffer_Array;
   Shape   : Dimension_Array;
   Strides : Dimension_Stride_Array;
   Process : not null access procedure (Image : Mat))

Read-only view of a strided N-dimensional buffer; the rules match the writable strided Shape overload. Strides count vectors, not bytes.

Parameters
Data

The caller-owned buffer that Image aliases; it may be an aliased constant. Its length must be at least Shape (first) * Strides (first).

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0).

Strides

One stride per dimension, in vectors; the final stride must be 1 and each outer stride must cover its nested inner block.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape or Strides violates the rules above, Shape has more dimensions than the linked OpenCV supports, or Data is too short.
