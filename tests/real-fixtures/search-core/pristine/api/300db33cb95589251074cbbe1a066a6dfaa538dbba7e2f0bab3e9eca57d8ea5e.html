Description

Checked element access to single-channel Float64 (CV_64FC1) Mats. Each element is one Float64_Value. Every operation validates the Mat's depth, channel count, dimension count and indices before touching storage and raises OpenCV_Error on any mismatch, so a wrong Mat type is never reinterpreted. Indices are zero-based. Writes go to the Mat's actual storage, so every shallow alias and the parent of a Region observe them.

Classify

function Classify
  (Image : Mat; Row, Column : Integer) return Float64_Classification

Classifies the stored Float64 value without converting non-finite IEEE values into the public Float64_Value subtype.

Parameters
Image

A two-dimensional Float64 Mat with exactly one channel.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Column

Zero-based column, in 0 .. Image.Columns - 1.

Return Value

Finite, Positive_Infinity, Negative_Infinity or Not_A_Number according to the stored element.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float64 single-channel two-dimensional Mat, Row or Column is outside the Mat, or the native classification fails.

Float64_Classification

type Float64_Classification is
  (Finite, Positive_Infinity, Negative_Infinity, Not_A_Number);

Result of Classify: the IEEE binary64 class of one stored element.

Enumeration Literal
Finite

The value is neither an infinity nor a NaN; zeros and subnormals are finite.

Positive_Infinity

The value is positive infinity.

Negative_Infinity

The value is negative infinity.

Not_A_Number

The value is a NaN of any sign or payload.

Get

function Get (Image : Mat; Indices : Index_Array) return Float64_Value

Zero-based N-dimensional access. Indices'Length must equal Image.Dimension_Count. Iteration order maps to OpenCV dimensions regardless of the array's index bounds.

Parameters
Image

A Float64 Mat with exactly one channel and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Return Value

The stored element value.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float64 single-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.
