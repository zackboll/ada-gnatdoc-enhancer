Description

Callback-scoped CV_16FC2 Mat headers over caller-owned Data. One Data entry is one complete 4-byte C2 element; each component is the exact stored IEEE-754 binary16 encoding (nothing is converted). Packed views require Data'Length = Rows * Columns or product (Shape). Strides count complete Float16_Vec2 elements, not scalar Float16 channels or bytes; the final N-D stride is 1 and padding is never touched. No data is copied and the caller retains ownership. The Mat is valid only during Process: shallow copies, Region, Slice and Reshape are rejected; Clone is the independent escape path. Component 0 and 1 are OpenCV channels 0 and 1; no semantic channel meaning is assigned. Shape, size and stride violations raise OpenCV_Error before the callback is invoked.

Buffer_Array

type Buffer_Array is array (Natural range <>) of Float16_Vec2.Vector;

A flat buffer of two-channel pixels supplied by the caller. Its index bounds are the caller's choice: only Data'First (the first pixel) and Data'Length (the capacity, counted in pixels) are used.

With_Read_Only_Mat_View

procedure With_Read_Only_Mat_View
  (Data    : aliased Buffer_Array;
   Shape   : Dimension_Array;
   Process : not null access procedure (Image : Mat))

Read-only view of a packed N-dimensional buffer, with the geometry rules of the writable N-dimensional overload.

Parameters
Data

The caller-owned packed buffer that Image aliases; it may be an aliased constant.

Shape

Extent of each dimension, in OpenCV dimension order.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape is invalid, has more dimensions than the linked OpenCV supports, or Data'Length differs from the product of Shape.

With_Read_Only_Strided_Mat_View

procedure With_Read_Only_Strided_Mat_View
  (Data    : aliased Buffer_Array;
   Shape   : Dimension_Array;
   Strides : Dimension_Stride_Array;
   Process : not null access procedure (Image : Mat))

Read-only view of a strided N-dimensional buffer, following the geometry, stride and capacity rules of the writable strided N-dimensional overload. Strides count complete pixels.

Parameters
Data

The caller-owned buffer that Image aliases; it may be an aliased constant. Its length, in pixels, must be at least Shape (first) * Strides (first).

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0).

Strides

One stride per dimension, in complete pixels; the final stride must be 1 and each outer stride must cover its nested inner block.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape or Strides violates the rules above, Shape has more dimensions than the linked OpenCV supports, or Data is too short.

Rows

Positive row count of Image.

Columns

Positive column count of Image.

With_Writable_Mat_View

procedure With_Writable_Mat_View
  (Data    : aliased in out Buffer_Array;
   Shape   : Dimension_Array;
   Process : not null access procedure (Image : in out Mat))

Invokes Process with a temporary writable packed N-dimensional CV_16FC2 Mat that aliases Data, with the final dimension varying fastest. Shape iteration order maps to OpenCV dimension order regardless of Shape'First.

Parameters
Data

The caller-owned packed buffer that Image aliases, passed by reference; its length, in pixels, must equal the product of Shape.

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0), in OpenCV dimension order.

Process

Callback that receives the temporary writable Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape has fewer than 2 or more than 32 dimensions (more than 10 on OpenCV 5.0), more dimensions than the linked OpenCV supports, an extent is zero, or Data'Length differs from the product of Shape.

Process

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Data'Length differs from Rows * Columns or a dimension exceeds the native range.

With_Writable_Strided_Mat_View

procedure With_Writable_Strided_Mat_View
  (Data    : aliased in out Buffer_Array;
   Shape   : Dimension_Array;
   Strides : Dimension_Stride_Array;
   Process : not null access procedure (Image : in out Mat))

Invokes Process with a temporary writable strided N-dimensional CV_16FC2 Mat that aliases Data. Strides supplies exactly one stride per dimension in the same order as Shape, counted in complete pixels. The final stride must be 1 and each outer stride must cover its nested inner block: Strides (I) >= Strides (I + 1) * Shape (I + 1).

Parameters
Data

The caller-owned buffer that Image aliases, passed by reference; its length, in pixels, must be at least Shape (first) * Strides (first).

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0).

Strides

One stride per dimension, in complete pixels (not scalar channels, not bytes); the final stride must be 1 and each outer stride must cover its nested inner block.

Process

Callback that receives the temporary writable Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape or Strides violates the rules above, Shape has more dimensions than the linked OpenCV supports, the two arrays differ in length, or Data is too short.

Rows

Columns

Positive column count of Image.

Row_Stride

Process

Callback that receives the temporary writable Image. It is valid only during the call and must not be retained.

Raised exceptions
