Description

Callback-scoped Mat views over caller-owned four-channel Float64 (CV_64FC4) buffers. Each Data entry is one complete four-channel element. A view never copies or owns the caller's Data: the temporary Mat handed to the callback aliases Data directly and is valid only during the callback. The writable forms let the callback modify Data through the Mat; the read-only forms pass the Mat in mode and accept constant Data. Strides are counted in complete four-channel elements (not scalars or bytes). Shape, size and stride violations raise OpenCV_Error before the callback is invoked. A temporary view cannot be retained or shallow-copied; use Clone to keep independent values.

Buffer_Array

type Buffer_Array is array (Natural range <>) of Float64_Vec4.Vector;

A flat buffer supplied by the caller, one four-channel vector per element. Index bounds are the caller's choice: only Data'First and Data'Length are used.

With_Read_Only_Mat_View

procedure With_Read_Only_Mat_View
  (Data    : aliased Buffer_Array;
   Shape   : Dimension_Array;
   Process : not null access procedure (Image : Mat))

Read-only view of a packed N-dimensional buffer, with the geometry rules of the writable N-dimensional overload.

Parameters
Data

The caller-owned packed buffer that Image aliases; it may be an aliased constant. Its length must equal the product of Shape.

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0), in OpenCV dimension order.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape is invalid, has more dimensions than the linked OpenCV supports, or Data'Length differs from the product of Shape.

With_Read_Only_Mat_View

procedure With_Read_Only_Mat_View
  (Data          : aliased Buffer_Array;
   Rows, Columns : Positive;
   Process       : not null access procedure (Image : Mat))

Read-only zero-copy caller-owned views (one Data entry per vector). Aliased constant Data is accepted; geometry/capacity are exactly those of the corresponding writable overloads. Mode-in Image prevents normal Ada mutation, not OS/page writes. Shallow escape is rejected; Clone owns independent pixels and Module_Interop input is allowed. This overload views a packed row-major buffer; Data'Length must equal Rows * Columns.

Parameters
Data

The caller-owned buffer that Image aliases; it may be an aliased constant. Its length must be Rows * Columns.

Rows

Positive row count of Image.

Columns

Positive column count of Image.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Data'Length differs from Rows * Columns or a dimension exceeds the native range.

With_Read_Only_Strided_Mat_View

procedure With_Read_Only_Strided_Mat_View
  (Data    : aliased Buffer_Array;
   Shape   : Dimension_Array;
   Strides : Dimension_Stride_Array;
   Process : not null access procedure (Image : Mat))

Read-only view of a strided N-dimensional buffer, following the geometry, stride and capacity rules of the writable strided N-dimensional overload.

Parameters
Data

The caller-owned buffer that Image aliases; it may be an aliased constant. Its length must be at least Shape (first) * Strides (first).

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0).

Strides

One stride per dimension, in complete four-channel elements; the final stride must be 1 and each outer stride must cover its nested inner block.

Process

Callback that receives the temporary read-only Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape or Strides violates the rules above, Shape has more dimensions than the linked OpenCV supports, or Data is too short.

With_Writable_Mat_View

procedure With_Writable_Mat_View
  (Data    : aliased in out Buffer_Array;
   Shape   : Dimension_Array;
   Process : not null access procedure (Image : in out Mat))

Packed N-D view: Shape'Length in 2 .. 32 (at most 10 on OpenCV 5.0), positive extents in OpenCV dimension order, Data'Length = product (Shape) complete C4 elements (not 4 * product scalars), final dimension fastest. Neither Ada lower bound is visible. No copy or narrowing; the caller keeps ownership; shallow escape (including Slice and Reshape) is rejected and Clone is the independent escape path.

Parameters
Data

The caller-owned packed buffer that Image aliases, passed by reference; its length must equal the product of Shape.

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0), in OpenCV dimension order.

Process

Callback that receives the temporary writable Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape has fewer than 2 or more than 32 dimensions (more than 10 on OpenCV 5.0), more dimensions than the linked OpenCV supports, an extent is zero, or Data'Length differs from the product of Shape.

With_Writable_Strided_Mat_View

procedure With_Writable_Strided_Mat_View
  (Data    : aliased in out Buffer_Array;
   Shape   : Dimension_Array;
   Strides : Dimension_Stride_Array;
   Process : not null access procedure (Image : in out Mat))

Strided N-D view: one stride per Shape dimension (bounds irrelevant), counted in complete Vec4 elements (32 bytes each), not scalars or bytes. Final stride is 1 and Strides (I) >= Strides (I + 1) * Shape (I + 1). Index (I1, .., In) is Data (Data'First + I1 * S1 + ..

  • In * Sn). Data'Length >= Shape (first) * Strides (first), including

final outer padding; extra trailing entries are allowed and padding is untouched. No copy or narrowing; the caller keeps ownership; shallow escape is rejected and Clone is the independent escape path.

Parameters
Data

The caller-owned buffer that Image aliases, passed by reference; its length must be at least Shape (first) * Strides (first).

Shape

Extent of each dimension, 2 to 32 positive values (at most 10 on OpenCV 5.0).

Strides

One stride per dimension, in complete four-channel elements; the final stride must be 1 and each outer stride must cover its nested inner block.

Process

Callback that receives the temporary writable Image. It is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Shape or Strides violates the rules above, Shape has more dimensions than the linked OpenCV supports, the two arrays differ in length, or Data is too short.

Columns
