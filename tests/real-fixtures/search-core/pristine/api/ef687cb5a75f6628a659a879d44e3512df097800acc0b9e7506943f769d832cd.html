Description

Checked element access to four-channel UInt8 (CV_8UC4) Mats. Each element is one OpenCV.Core.UInt8_Vec4.Vector holding the four interleaved channel values of one complete pixel in native channel order. Every operation validates the Mat's depth, channel count, dimension count and indices before touching storage and raises OpenCV_Error on any mismatch. Indices are zero-based. Writes go to the Mat's actual storage, so every shallow alias and the parent of a Region observe them.

Get

function Get (Image : Mat; Indices : Index_Array) return UInt8_Vec4.Vector

Zero-based N-dimensional access. Indices'Length must equal Image.Dimension_Count. Iteration order maps to OpenCV dimensions regardless of the array's index bounds. One vector is one complete four-channel element.

Parameters
Image

A UInt8 Mat with exactly four channels and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Return Value

The four channel values of the element.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt8 four-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.

Get

function Get (Image : Mat; Row, Column : Integer) return UInt8_Vec4.Vector

Reads the complete element at a zero-based row and column of a two-dimensional Mat.

Parameters
Image

A two-dimensional UInt8 Mat with exactly four channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Column

Zero-based column, in 0 .. Image.Columns - 1.

Return Value

The four channel values of the element.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt8 four-channel two-dimensional Mat, or Row or Column is outside the Mat.

Zero-based N-dimensional write of one complete four-channel element; the indexing rules of the matching Get apply. All four channels are stored together, in the Mat's actual storage, and are visible through every header sharing it.

Parameters

A UInt8 Mat with exactly four channels and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Value

The four channel values to store.

Raised exceptions
OpenCV_Error
