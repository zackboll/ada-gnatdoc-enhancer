Description

Checked element access to single-channel UInt8 (CV_8UC1) Mats. Each element is one UInt8_Value. Every operation validates the Mat's depth, channel count, dimension count and indices before touching storage and raises OpenCV_Error on any mismatch, so a wrong Mat type is never reinterpreted. Indices are zero-based. Writes go to the Mat's actual storage, so every shallow alias and the parent of a Region observe them.

Get

function Get (Image : Mat; Indices : Index_Array) return UInt8_Value

Zero-based N-dimensional access. Indices'Length must equal Image.Dimension_Count. Iteration order maps to OpenCV dimensions regardless of the array's index bounds.

Parameters
Image

A UInt8 Mat with exactly one channel and at least one dimension.

Indices

One zero-based index per dimension, each less than the matching extent.

Return Value

The stored element value.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt8 single-channel Mat, Indices does not have exactly one entry per dimension, or an index is out of range.

Get

function Get (Image : Mat; Row, Column : Integer) return UInt8_Value

Reads the element at a zero-based row and column of a two-dimensional Mat.

Parameters
Image

A two-dimensional UInt8 Mat with exactly one channel.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Column

Zero-based column, in 0 .. Image.Columns - 1.

Return Value

The stored element value.

Raised exceptions
OpenCV_Error

Raised when Image is not a UInt8 single-channel two-dimensional Mat, or Row or Column is outside the Mat.
