Description

Zero-copy, callback-scoped access to the complete element buffer of a continuous four-channel UInt16 (CV_16UC4) Mat of any dimension count. Each buffer entry is one complete four-channel pixel. The view aliases native storage and is valid only during the callback. Every operation validates the Mat's depth, channel count and continuity and raises OpenCV_Error on any mismatch, before the callback is invoked.

Buffer_Array

type Buffer_Array is array (Natural range <>) of UInt16_Vec4.Vector;

The flat element buffer of a Mat: one UInt16_Vec4.Vector per Mat element, in OpenCV element order with the final dimension varying fastest.

With_Read_Only_Buffer

procedure With_Read_Only_Buffer
  (Image   : Mat;
   Process : not null access procedure (Data : aliased Buffer_Array))

Continuous Mats only; one entry per complete C4 element. A shallow lease retains storage until Process returns. Data is a flat array of all Mat elements, in OpenCV element order with the final dimension varying fastest. An empty Mat of the right type is accepted.

Parameters
Image

A continuous UInt16 Mat with exactly four channels.

Process

Callback that receives the borrowed buffer. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a UInt16 four-channel Mat or is nonempty and not continuous, or has more elements than Natural'Last.

With_Writable_Buffer

procedure With_Writable_Buffer
  (Image   : in out Mat;
   Process :
     not null access procedure (Data : aliased in out Buffer_Array))

As With_Read_Only_Buffer, except Process receives an in-out view whose writes mutate the actual Mat storage immediately.

Parameters
Image

A continuous UInt16 Mat with exactly four channels.

Process

Callback that receives the borrowed buffer for reading and writing. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a UInt16 four-channel Mat or is nonempty and not continuous, or has more elements than Natural'Last.
