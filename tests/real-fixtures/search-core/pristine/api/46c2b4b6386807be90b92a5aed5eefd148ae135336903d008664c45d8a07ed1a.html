Zero-based column position within a row.

Read_Row

procedure Read_Row (Image : Mat; Row : Natural; Data : out Row_Array)

Copies one row of Image into Data. Data'Length must equal Image.Columns; Data (Data'First) receives column 0. Image is unchanged and Data owns its values.

Parameters
Image

A two-dimensional Float32 Mat with exactly two channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Data

Receives one two-channel pixel per column.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float32 two-channel Mat, Row is outside the Mat, or Data'Length differs from Image.Columns.

Row_Array

type Row_Array is array (Natural range <>) of Float32_Vec2.Vector;

The pixels of one Mat row, one Float32_Vec2.Vector per column. Array bounds are the caller's choice: only the length matters, and the first array element always corresponds to column 0.

With_Read_Only_Row

procedure With_Read_Only_Row
  (Image   : Mat;
   Row     : Natural;
   Process : not null access procedure (Data : aliased Row_Array))

Borrowed storage is valid only during Process; no references may escape. Invokes Process with a zero-copy view of one Float32 C2 Mat row. Data aliases native storage for that row, one complete pixel per element, and is indexed with zero-based columns (Data'Length = Image.Columns).

Parameters
Image

A two-dimensional Float32 Mat with exactly two channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Process

Callback that receives the borrowed row. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a two-dimensional Float32 two-channel Mat or Row is outside the Mat.

With_Writable_Row

procedure With_Writable_Row
  (Image   : in out Mat;
   Row     : Natural;
   Process : not null access procedure (Data : aliased in out Row_Array))

As With_Read_Only_Row, except Process receives an in-out view; writes through Data mutate the actual Mat storage immediately.

Parameters
Image

A two-dimensional Float32 Mat with exactly two channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Process

Callback that receives the borrowed row for reading and writing. Data is valid only during the call and must not be retained.

Raised exceptions
OpenCV_Error

Raised, before Process is invoked, when Image is not a two-dimensional Float32 two-channel Mat or Row is outside the Mat.

Write_Row

procedure Write_Row (Image : in out Mat; Row : Natural; Data : Row_Array)

Copies Data into one row of Image. Data'Length must equal Image.Columns; Data (Data'First) is stored in column 0. The values are written to the Mat's actual storage, so shallow aliases and the parent of a Region observe them.

Parameters
Image

A two-dimensional Float32 Mat with exactly two channels.

Row

Zero-based row, in 0 .. Image.Rows - 1.

Data

One two-channel pixel per column.

Raised exceptions
OpenCV_Error

Raised when Image is not a Float32 two-channel Mat, Row is outside the Mat, or Data'Length differs from Image.Columns.
