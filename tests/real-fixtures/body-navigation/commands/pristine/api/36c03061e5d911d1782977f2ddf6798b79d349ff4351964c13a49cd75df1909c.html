Description

Opaque control-only Image checkout notifications, not image samples. No application callback runs on a provider thread. Serialize operations and Close on each public owner; independent leases may close concurrently. Prefer explicit Close. Finalization never raises or retries an uncertain release. Provider failures can permanently retain storage and provider code.

Checkout_Lease

type Checkout_Lease is limited private;

Unique owner of one actual callback Buffer; exposes no address or pixels.

Checkout_Receiver

type Checkout_Receiver is limited private;

One-shot bounded receiver retaining the native Image and Session graph.

Close

procedure Close (Lease : in out Checkout_Lease)

Idempotently consume this lease and release the exact callback Buffer once, outside bridge locks. Failed/throwing release permanently retains its graph; the public lease is still consumed and finalization never retries release.

Parameters
Lease

Owner cleared even when the provider release fails.

Raised exceptions
Provider_Error

Release failed or threw; actual Return is reported when available, otherwise the explicit no-Return sentinel is reported.

Close

procedure Close (Receiver : in out Checkout_Receiver)

Stop admission, wake waiters and drain queued wrappers through the same release engine. Live leases survive. No Disable, unregister or detach.

Parameters
Receiver

Owner consumed even if draining reports uncertainty.

Raised exceptions
Provider_Error

Drain failed; exact uncertain owners stay retained.

   Checkouts_Accepted,
   Queue_Overflow,
   Callbacks_Rejected,
   Releases_Succeeded,
   Releases_Uncertain : Interfaces.Unsigned_64;
end record;

Independent cumulative saturating counters, including rejected callbacks.

Record fields
Callbacks_Received

All callbacks, including null deliveries.

Checkouts_Accepted

Actual wrappers transferred into the FIFO.

Queue_Overflow

Rejections at queue or outstanding owner capacity.

Callbacks_Rejected

Callbacks not accepted as opaque checkouts.

Releases_Succeeded

Successful release and safe wrapper destruction.

Releases_Uncertain

Failed release or conservative retained ownership.

Open

function Open
  (Object         : AMS.MEL.IR.Image_Stream;
   Queue_Capacity : Positive := 16;
   Max_Checkouts  : Positive := 16) return Checkout_Receiver

Install once before first Start, without a listener or image-buffer pool. Preallocates Max_Checkouts + 2 HOLD/deferred/uncertain slots for callback overlap. Max_Checkouts bounds queued plus leased owners. Excess delivery is rejected/released or retained; exhaustion of the process-wide 64-owner emergency reserve is fail-stop rather than unsafe wrapper destruction.

Parameters
Object

Attached control-only Image; full acquisition is refused.

Queue_Capacity

Positive FIFO bound, at most Max_Checkouts.

Max_Checkouts

Maximum simultaneous queued and leased HOLD owners.

Return Value

Open receiver; closing it does not permit a second installation.

Raised exceptions
Provider_Error

Invalid lifecycle, capacity or allocation failure.

Receive

function Receive
  (Receiver : Checkout_Receiver; Timeout_Milliseconds : Natural := 0) return Checkout_Lease

Transfer the oldest delivered wrapper without retiring its obligation. Acceptance requires Running and completed active application registration.

Parameters
Receiver

Open receiver, externally serialized against Close.

Timeout_Milliseconds

Maximum wait; zero is a nonblocking poll.

Return Value

Unique opaque lease, with no claim of valid image data.

Raised exceptions
Timeout_Error

No checkout arrived; receiver is not cancelled.

Provider_Error

Receiver stopped, native or provider failure.
