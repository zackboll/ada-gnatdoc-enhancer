Description

Required ChannelCommsTestRep reception for Health, Image and StackedImage. C2 uses C2.Metadata.Enable_Comms_Test_Events and its existing shared queue. No callback is inferred from a request future. Serialize operations and Close on the same stream. No Ada code executes on a provider thread.

Close

procedure Close (Stream : in out Comms_Metadata_Stream)

Idempotently deactivate/release consumption, not unregister the callback. Does not retain or close the typed channel, or promise disable quiescence. Prefer explicit Close; finalization attempts non-raising cleanup.

Parameters
Stream

Consumer to deactivate and release; already closed is harmless.

Raised exceptions
Provider_Error

Native close failure.

Comms_Metadata_Stream

type Comms_Metadata_Stream is limited private;

Limited consumer of a native queue of copied communications-test reports. The stream has only a weak link to the typed channel; installed callbacks retain queue state independently of this owner. Explicit Close is preferred; finalization attempts non-raising cleanup. Serialize operations on the same stream. Callback delivery is independent of request-future completion.

Metadata_Counters

type Metadata_Counters is record
   Events_Received           : Counter;
   Events_Dropped_Queue_Full : Counter;
   Malformed_Or_Unsupported  : Counter;
end record;

Snapshot of saturating callback diagnostics; each count stops at Counter'Last.

Record fields
Events_Received

Callback invocations, including null reports, full-queue drops and reports delivered after admission stops; not a dequeue count.

Events_Dropped_Queue_Full

Incoming valid reports dropped because the active FIFO was full; previously accepted reports are preserved.

Malformed_Or_Unsupported

Null callback reports rejected without enqueueing.

Open

function Open (Channel : View; Queue_Capacity : Positive := 16) return Comms_Metadata_Stream

Explicit one-shot registration while Health/Stacked is Attached or Enabled, or Image is Attached/Running, including a control-only Image attachment. No layout or capability-advertisement prerequisite. Failure consumes the typed channel's attempt even through another weak View. Synchronous delivery is supported. Refusal/exception raises Provider_Error; no owner escapes. Partially installed callbacks retain inactive queue state.

Parameters
Channel

Weak view of an eligible Health, Image or StackedImage owner whose communications-metadata registration has not been attempted.

Queue_Capacity

Positive maximum number of queued reports, default sixteen.

Return Value

Limited consumer of the channel's communications-test callback reports.

Raised exceptions
Provider_Error

Closed, expired or ineligible channel, repeated registration attempt, provider refusal or exception, or native open failure.

Receive

function Receive
  (Stream : Comms_Metadata_Stream; Timeout_Milliseconds : Natural := 0) return Comms_Test_Report

Copies one complete command/request ID pair, preserving all 32 bits. FIFO drops incoming events when full. Zero polls, finite timeout raises Timeout_Error without cancellation. Queued copies drain after typed closure, then Stream_Stopped (or Provider_Error for cleanup failure). Channel association is this stream, never a numeric request selector.

Parameters
Stream

Open communications-metadata consumer.

Timeout_Milliseconds

Maximum queue wait in milliseconds; zero polls.

Return Value

Oldest queued report, copied independently of native owners and futures.

Raised exceptions
Timeout_Error

Active queue remained empty until the wait expired, including an empty poll. Registration and requests are not cancelled.

Stream_Stopped

Inactive or stopped queue is empty after queued reports have drained.

Provider_Error

Closed stream, callback or typed-channel cleanup failure after queued reports drain, or native receive failure.
