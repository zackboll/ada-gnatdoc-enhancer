Description

Independent opt-in reception of the pinned @RequiredIfIRSTTrackTasking ExecuteTaskAck and TaskExecutingRep callbacks. Reception and provider task execution are separate events. An acknowledgement means only that the provider delivered this value: it proves neither completion nor success. No Scheduling exec/send, local request matching, identifier reordering or uniqueness rule is implemented. Qualification uses the separate mock provider only.

Close

procedure Close (Stream : in out Execute_Task_Ack_Stream)

Idempotently deactivate consumption, without unregistering, closing the Scheduling owner or waiting for callback quiescence. Already returned Ada values remain owned. Physical teardown retains the provider graph until in-flight bridge callbacks have drained.

Parameters

Metadata owner to close.

Raised exceptions
Provider_Error

Native closure failed.

Record fields

All 32 bits of upstream getCommandID(), including zero and high bits.

All 32 bits of upstream getReqId(), independent of Command_ID. Zero, unequal and duplicate identifiers are all valid; this is not a completion status.

Execute_Task_Ack_Stream

type Execute_Task_Ack_Stream is limited private;

Limited controlled consumption owner. Explicit Close is preferred; finalization attempts non-raising cleanup. Serialize operations and Close on the same stream externally. A Scheduling Close may run while Receive waits: it stops consumption and wakes the receiver.

Metadata_Counters

type Metadata_Counters is record

   Events_Dropped_Queue_Full : AMS.MEL.IR.Counter;
   Malformed_Or_Unsupported  : AMS.MEL.IR.Counter;
end record;

Saturating callback counters, not successful Ada Receive calls.

Record fields
Events_Received

Callback entries, including inactive callbacks and rejected events.

Events_Dropped_Queue_Full

Valid incoming events dropped without snapshot allocation because the bounded queue is full. Already queued events are retained.

Malformed_Or_Unsupported

Null payloads (even while full) and callback allocation or copy failures. A failed event is rejected atomically; later reception can recover.

Not_Supported

Not_Supported : exception;

The provider answered NotSupported for the requested ExecuteTaskAck or TaskExecutingRep registration. The Scheduling owner and its inherited common Channel services are unaffected.

Open_Execute_Task_Ack

function Open_Execute_Task_Ack
  (Channel : Scheduling_Channel; Queue_Capacity : Positive) return Execute_Task_Ack_Stream

Register exactly the ExecuteTaskAck overload once per Attached or Enabled Scheduling channel, including failed attempts. No foundation operation implicitly registers it. Registration runs without bridge locks and may deliver synchronously. No unregister exists; after failure retained callback state is inactive. No task is submitted.

Parameters
Channel

Attached or Enabled Scheduling owner, serialized against its closure.

Queue_Capacity

Maximum number of events in the bounded drop-incoming queue.

Return Value

Independent limited metadata consumption owner.

Raised exceptions
Not_Supported

Provider answered NotSupported.

Provider_Error

Ineligible/closed owner, second attempt, other refusal, provider exception or native allocation failure.

Receive_Execute_Task_Ack

function Receive_Execute_Task_Ack
  (Stream : Execute_Task_Ack_Stream; Timeout_Milliseconds : Natural := 0)
   return Execute_Task_Ack

Dequeue in successful-enqueue order; copy both identifiers and release the native event before returning, including on conversion failure. Queued events drain after Scheduling Close, even while common requests defer physical teardown; terminal cleanup failure is reported only after that queue drains. Reception is not execution completion or success.

Parameters

Timeout_Milliseconds

Return Value

Fully Ada-owned acknowledgement, valid after all owners and the provider close.

Raised exceptions

Active queue remained empty until the wait expired.

Stream_Stopped

Inactive or stopped queue is empty.

Provider_Error

Closed stream, failed provider cleanup or native failure.

Task_Completion_Status

type Task_Completion_Status is (Status_No_Task, Complete, Timeout, Abort_Status, Skipped);

Pinned upstream TaskCompStatus, values 0..4, a type separate from Task_Kind. In a report it describes the PREVIOUS task only, never the current task. Other values are rejected.

Enumeration Literal
Status_No_Task

Upstream NoTask, value 0; prefixed to avoid the Task_Kind literal.

Complete

Upstream Complete, value 1.

Timeout

Upstream Timeout, value 2; a reported outcome, not a bridge timeout.

Abort_Status

Upstream Abort, value 3; renamed because abort is reserved in Ada.

Skipped

Upstream Skipped, value 4.

Task_Executing_Report

type Task_Executing_Report is record
   Command_ID            : Interfaces.Unsigned_32 := 0;
   Activity_ID           : Interfaces.Unsigned_32 := 0;
   Request_ID            : Interfaces.Unsigned_32 := 0;
   Current_Task          : Task_Kind := No_Task;
   Estimated_Duration_NS : Interfaces.Integer_64 := 0;
   Track_ID              : Interfaces.Integer_32 := 0;
   Previous_Activity_ID  : Interfaces.Unsigned_32 := 0;
   Previous_Request_ID   : Interfaces.Unsigned_32 := 0;
   Previous_Task         : Task_Kind := No_Task;
   Previous_Task_Status  : Task_Completion_Status := Status_No_Task;
end record;

Complete Ada-owned report of all ten upstream getters, independent of the native event and provider graph. Defaults equal the upstream defaults. Current and previous values are independent; no relationship between them is inferred or enforced.

Record fields
Command_ID

All 32 bits of upstream getCommandID().

Activity_ID

All 32 bits of upstream getActivityId() for the current task.

Request_ID

All 32 bits of upstream getReqId() for the current task.

Current_Task

Upstream getTask(), the reported currently executing task kind.

Estimated_Duration_NS

Exact signed upstream getEstimatedDuration().count() in nanoseconds; never converted to seconds, Duration or a time point. Negative is preserved.

Track_ID

Signed upstream getTrackId(); negative and zero values are preserved.

Previous_Activity_ID

All 32 bits of upstream getPrevActivityId().

Previous_Request_ID

All 32 bits of upstream getPrevReqId().

Previous_Task

Upstream getPrevTask(), the reported previous task kind.

Previous_Task_Status

Upstream getPrevTaskStatus(): the previous task's reported completion status, not a status of Current_Task.

Task_Kind

type Task_Kind is
  (No_Task,
   Abort_Task,
   IRST_Camera_Calibration,
   Camera_Calibration,
   IRST_Boresight,
   Idle,
   IRST_Scan,
   IRST_Position,
   …,
   Reserved_6);

Every defined pinned upstream Task value, in numeric order 0..16. Reserved_1 through Reserved_6 are preserved exactly as reported but carry no operational meaning and are not supported or executable task kinds. The NumTaskTypes count sentinel (17) and every larger value are not representable: such a report is rejected whole.
