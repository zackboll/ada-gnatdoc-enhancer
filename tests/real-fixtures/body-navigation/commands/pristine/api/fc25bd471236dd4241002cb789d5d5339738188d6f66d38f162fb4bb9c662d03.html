Description

Standalone provider Buffer with stable, zero-initialized bridge-owned host bytes. Channel.Register_Buffer retains its native graph without transferring ownership. No acquisition, image view or checkout release. While registration is active or uncertain, property/byte/flag operations and Close raise Provider_Error. Successful unregister must also reconcile remaining provider ownership before these operations become available. Serialize operations and closure on each owner. GPU/RDMA flags are only provider bookkeeping, never physical GPU/RDMA allocation promises.
