Description

Outgoing task requests, independent of Scheduling metadata. A future reports the provider's Return or rejection, not physical sensor activity.

Abort_Request

type Abort_Request is limited private;

Limited controlled observer; finalization never raises. Closing an observer does not cancel admitted work. Serialize Wait and Close on this observer.

Abort_Result

type Abort_Result is private;

Owned cached terminal result, independent of all provider owners.

Stare_Request

type Stare_Request is limited private;

Limited-controlled Return observer sharing Wait, Close and non-raising finalization with Abort_Request. Timeout and Close do not cancel work.

Stare_Result

type Stare_Result is private;

Owned cached Return or MEL rejection; uses Status, Value, Rejection_Code and Description below. No acknowledgement or execution report is inferred.
