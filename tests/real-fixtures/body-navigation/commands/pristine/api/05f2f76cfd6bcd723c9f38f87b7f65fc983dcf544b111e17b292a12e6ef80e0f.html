Description

Safe Stacked attachment and lifecycle only. Serialize public operations and Close on a shared typed owner externally.

As_Channel

function As_Channel (Channel : Stacked_Channel) return AMS.MEL.IR.Channel.View

Allocate a weak common view (KeepAlive, CommsTest, Capabilities, Disable) without changing lifecycle. Closing the view leaves this owner intact; closing this owner makes later view operations fail. Admitted common requests retain their own lifetime and use Stacked-only request accounting.

Parameters
Channel

Open Stacked owner to reference weakly.

Return Value

Weak common view; its handle presence does not prove target existence.

Capabilities

function Capabilities (Channel : Stacked_Channel) return AMS.MEL.IR.Channel.Channel_Capability

Copy the complete provider snapshot while Attached or Enabled, preserving zero layout fields and empty nested collections. No acquisition format is inferred. Closed/failed lifecycle or conversion errors raise Provider_Error.

Parameters
Channel

Eligible Stacked owner, externally serialized against Close.

Return Value

Owned snapshot valid after channel, Session and provider closure.

Close

procedure Close (Channel : in out Stacked_Channel)

Stop public admission and close the owner without cancelling futures. Use Channel.Disable for non-terminal disable. Close calls provider disable only for an outstanding enable cycle, then detaches. Physical teardown waits for admitted common requests. A detach failure retains the graph and handle for retry; a disable failure after a successful detach still raises.

Parameters
Channel

Stacked owner to close; serialize against its public operations.

Enable

procedure Enable (Channel : in out Stacked_Channel)

Explicitly call the inherited Channel enable on an Attached owner; an already Enabled owner is idempotent. Provider refusal or exception raises a provider error and marks failure; retrying Enable does not recover it. Enabling allocates no buffers and installs no listeners.

Parameters
Channel

Open Attached or already Enabled owner; serialize owner operations.

Open

function Open (Parent : Session; Config : Stacked_Config) return Stacked_Channel

Require an open Session that publishes the Stacked category, attach once with ChannelType StackedImage (value 6), and verify the concrete StackedImageChannel interface and its advertised category. Configuration text is validated natively. Failure raises a provider error and no owner escapes; an ownership-uncertain incompatible attachment stays retained.

Parameters
Parent

Open Session whose native graph is retained by the child.

Config

Owned attachment values copied before provider use.

Return Value

Attached, not Enabled, Stacked owner.

Stacked_Channel

type Stacked_Channel is limited private;

Limited controlled owner of an attached provider Stacked channel. It retains the native Session graph and provider library independently of the parent Ada Session. Admitted common requests keep their own native lifetime and can defer physical teardown after public closure. Finalization is non-raising.

Stacked_Config

type Stacked_Config is private;

Owned channel/platform UCI identities and sensor component location for a Stacked attachment; creating a value performs no provider operation.
