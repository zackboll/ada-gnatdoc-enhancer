Description

Root package of the Ada binding to OpenCV.

This package owns the value types shared by every module crate: numeric element subtypes, integer and binary32 geometry, Scalar, and the common Border_Kind and Angle_Unit options. Module packages such as OpenCV.Core and crates that depend on opencv_core reuse these declarations instead of redeclaring them. OpenCV.Core owns Mat and matrix-specific abstractions.

The types here describe how values are represented. Whether a particular value is acceptable is decided by each operation that consumes it.

Angle_Unit

type Angle_Unit is (Radians, Degrees);

Unit used to express an angle.

Enumeration Literal
Radians

Angles are measured in radians.

Degrees

Angles are measured in degrees.

Border_Kind

type Border_Kind is
  (Constant_Border, Replicate, Reflect, Reflect_101, Wrap);

Rule for supplying pixels outside the image boundary, corresponding to OpenCV's cv::BorderTypes. Individual operations may support only some of these kinds and define any further restrictions.

Enumeration Literal
Constant_Border

Outside pixels take a caller-supplied constant value.

Replicate

The outermost pixel is repeated outward.

Reflect

The image is mirrored about the edge, repeating the edge pixel.

Reflect_101

The image is mirrored about the edge without repeating the edge pixel.

Wrap

The image is treated as periodic and continues from the opposite edge.

Make_Scalar

function Make_Scalar
  (Component_0 : Long_Float;
   Component_1 : Long_Float := 0.0;
   Component_2 : Long_Float := 0.0;
   Component_3 : Long_Float := 0.0) return Scalar

Build a Scalar from up to four components in channel order. Component_0 is stored first; how the components map to colors is determined by the operation that consumes the Scalar.

Parameters
Component_0

Value stored in component 0.

Component_1

Value stored in component 1. Defaults to 0.0.

Component_2

Value stored in component 2. Defaults to 0.0.

Component_3

Value stored in component 3. Defaults to 0.0.

Return Value

A Scalar whose components equal the arguments.

Point

type Point is record
   X : Point_Coordinate := 0;
   Y : Point_Coordinate := 0;
end record;

Integer two-dimensional point with signed 32-bit coordinates. Mat indices are zero-based, so (0, 0) addresses the first row and column. The type itself places no bounds on either coordinate.

Record fields
X

Horizontal coordinate (column direction).

Y

Vertical coordinate (row direction).

Point_Array

type Point_Array is array (Natural range <>) of Point;

A zero-based, value-semantic sequence of points. An empty result has the null range 1 .. 0.

Point_Coordinate

type Point_Coordinate is new Interfaces.Integer_32;

Signed 32-bit integer coordinate, used for point positions and rectangle origins. Negative values are representable. Individual operations define which positions they accept, for example Mat element access requires coordinates inside the matrix.

Rect

type Rect is record
   X      : Point_Coordinate := 0;
   Y      : Point_Coordinate := 0;
   Width  : Size_Coordinate := 0;
   Height : Size_Coordinate := 0;
end record;

Axis-aligned rectangle with a signed origin and nonnegative size. OpenCV rectangle origins may be negative. Width and Height remain nonnegative in this Ada value model. A Rect is not restricted merely because Mat ROI operations require nonnegative origins; Mat.Region enforces that ROI-specific constraint itself.

Record fields
X

Horizontal coordinate of the signed origin.

Y

Vertical coordinate of the signed origin.

Width

Nonnegative horizontal extent from the origin.

Height

Nonnegative vertical extent from the origin.

Rotated_Rect

type Rotated_Rect is record
   Center        : Float32_Point := (X => 0.0, Y => 0.0);
   Size          : Float32_Size := (Width => 0.0, Height => 0.0);
   Angle_Degrees : Float32_Value := 0.0;
end record;

Value-semantic rotated rectangle with binary32 native OpenCV fields. Angle_Degrees is deliberately not normalized because different OpenCV operations and versions can use distinct equivalent representations.

Record fields
Center

Center point of the rectangle.

Size

Width and height of the rectangle.

Angle_Degrees

Rotation angle in degrees, stored as given by the producer or caller. No normalization range or rotation direction is guaranteed by this type.

Scalar

type Scalar is record
   Component_0 : Long_Float := 0.0;
   Component_1 : Long_Float := 0.0;
   Component_2 : Long_Float := 0.0;
   Component_3 : Long_Float := 0.0;
end record;

Ordered quadruple of binary64 values, the counterpart of cv::Scalar. It is used for per-channel values such as fill colors. The type only stores four numbers; it does not select or enforce a color space.

Record fields
Component_0

First component (channel 0).

Component_1

Second component (channel 1).

Component_2

Third component (channel 2).

Component_3

Fourth component (channel 3).

Size

type Size is record
   Width  : Size_Coordinate := 0;
   Height : Size_Coordinate := 0;
end record;

Integer two-dimensional extent. Both components are nonnegative Size_Coordinate values.

Record fields
Width

Horizontal extent, in the same units as Point.X.

Height

Vertical extent, in the same units as Point.Y.

Size_Coordinate

type Size_Coordinate is
  new Interfaces.Integer_32 range 0 .. Interfaces.Integer_32'Last;

Nonnegative 32-bit integer extent, used for widths and heights. The type represents zero through Integer_32'Last. Individual operations may accept only a subset, for example requiring a positive extent or one that fits a particular image.
