Description

Canonical owned values and request result for the pinned upstream CameraProtectCmd, CmdResp and CameraProtectCmdResp (@RequiredIfCameraProtect). One definition is shared by C2.Submit_Camera_Protection and the opt-in C2.Metadata camera-protection owner. No response deadline, camera behaviour or automatic retry is introduced by the bridge.

Not_Supported

Not_Supported : exception;

The provider answered NotSupported for the C2 CameraProtectCmdResp registration. This is distinct from a registration failure, a provider exception, an asynchronous MEL rejection and the Protection_Unsupported response value; existing C2 owners are unaffected.

Outcome

Success (a response with any of the three Status values) or explicit MEL rejection.

Protection_Command

type Protection_Command is record
   ID               : Command_ID := 0;
   Response_Time_NS : Nanoseconds := 0;
   Protect          : Boolean := False;
end record;

Owned copy of all three CameraProtectCmd fields; defaults equal the upstream defaults.

Record fields
ID

Unique command identifier supplied by the caller.

Response_Time_NS

Response time for this command, signed nanoseconds, passed unconverted; the bridge enforces no deadline.

Protect

True enables camera self-protection; False disables it.

Protection_Request

type Protection_Request is new AMS.MEL.IR.Camera_Protection_Request_Owner with private;

Limited request owner returned by C2.Submit_Camera_Protection. Pending native work retains its C2 channel, Session and provider library after request/channel/Session closure; finalization is non-raising and Close never cancels provider work.

Protection_Response

Owned copy of all three CameraProtectCmdResp fields, independent of native owners.

Record fields
ID

Command identifier reported by the MFA.

Response_Time_NS

Response time reported by the MFA, signed nanoseconds.

Status

Exact CmdResp alternative reporting the MFA camera self-protection capability.

Protection_Result

type Protection_Result is private;

Owned terminal request result: a response or an explicit rejection. Provider exceptions, null successful responses, unknown CmdResp values, unknown error codes and deferred cleanup failure raise exceptions rather than becoming results.

Protection_Status

type Protection_Status is (Protection_OK, Protection_Unavailable, Protection_Unsupported);

Exactly the three pinned CmdResp alternatives. Every value is a successful provider response; none is a MEL rejection or a registration NotSupported result. Unknown native values are never remapped to one of these and raise Provider_Error instead.

Enumeration Literal
Protection_OK

Upstream CmdResp::OK, value 0: the MFA reports protection capability.

Protection_Unavailable

Upstream CmdResp::Unavailable, value 1: protection is currently unavailable.

Protection_Unsupported

Upstream CmdResp::Unsupported, value 2: protection is not supported by the MFA.

Wait

function Wait

Wait finitely for the terminal result. Timeout raises Timeout_Error and neither consumes nor cancels the request; repeated terminal waits return the cached result.

Parameters

Timeout_Milliseconds

Return Value

Raised exceptions
