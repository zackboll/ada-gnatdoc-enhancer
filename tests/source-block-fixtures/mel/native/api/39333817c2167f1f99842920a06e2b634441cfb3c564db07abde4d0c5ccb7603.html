Description

Optional outbound C2 system Track data response. Positive qualification is mock-only. A successful future means only that the provider returned a CommandStatus; it does not establish operational incorporation of the data.

Response_Request

type Response_Request is limited private;

Limited controlled C2 observer, distinct from the Track response owner. Finalization closes without raising. Closing never cancels provider work; pending native work retains the C2/Session/provider graph independently.

Response_Result

type Response_Result is private;

Owned terminal C2 result: a successful CommandStatus or an explicit ErrorOr rejection with its complete diagnostic. Provider exceptions, null/malformed payloads, unknown codes and cleanup failures raise Provider_Error instead. Distinct from the Track overload's result type.
