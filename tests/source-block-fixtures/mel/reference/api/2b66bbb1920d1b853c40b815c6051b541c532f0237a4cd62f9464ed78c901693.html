Description

Complete owned values for the pinned optional CalibrationConfiguration. No Request_ID correlation, calibration execution or CalibrationStatus support is asserted.

Accepted_Interface

type Accepted_Interface is (Not_Set, Subsystem_Calibration_Command, Subsystem_State_Command);

Exactly pinned values 0, 1, 2. MaxExclusive and future values are rejected, never remapped.

Enumeration Literal
Not_Set

Upstream NotSet (0), a meaningful unset interface.

Subsystem_Calibration_Command

Upstream SubsystemCalibrationCommand (1).

Subsystem_State_Command

Upstream SubsystemStateCommand (2).

Subsystem_Calibration

type Subsystem_Calibration is record
   Calibration_ID  : UCI_ID;
   Interface_Value : Accepted_Interface := Not_Set;
   Item_Names      : Name_Vectors.Vector;
   Component_IDs   : ID_Vectors.Vector;
   Capability_IDs  : ID_Vectors.Vector;
end record;

Fully owned entry. Each nested vector has independent length and order. UCI_ID retains every UUID byte and its complete descriptive label.

Record fields
Calibration_ID

Complete calibration identity, including descriptive label.

Interface_Value

Exact accepted-interface alternative, never a boundary sentinel.

Item_Names

Ordered non-component/non-capability names, independent of ID vectors.

Component_IDs

Ordered subsystem component identifiers, not zipped with other vectors.

Capability_IDs

Ordered capability identifiers, not zipped with other vectors.

Wait

function Wait
  (Request : Configuration_Request; Timeout_Milliseconds : Natural) return Configuration_Result

Finite wait; Timeout_Error is not cancellation. Repeated Wait copies the cached result. Provider/future exceptions, invalid data, null success and cleanup failures raise Provider_Error.

Parameters

Open request owner; serialize against Close.

Timeout_Milliseconds

Maximum wait in milliseconds; zero polls.

Return Value

Owned success configuration or explicit MEL rejection.

Raised exceptions

Provider_Error

Closed request, native failure, malformed provider result or deferred cleanup failure.
