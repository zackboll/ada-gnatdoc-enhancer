Description

Enumerate advertised identities before choosing channels to attach. Discovery neither attaches channels nor establishes that their advertised sensor operations are functional. Serialize calls against Session closure and other provider operations; no concurrent-close protocol is provided.

Capabilities

function Capabilities (Session : AMS.MEL.Session) return Capability_Vectors.Vector

Copy the complete Control capability list in provider enumeration order. An empty vector is valid. Zero image dimensions, bit depth, band count and sizes remain zero: an unconfigured sensor need not advertise a stream layout yet. All nested values are Ada-owned and remain usable after the Session closes and the provider library unloads.

Parameters
Session

Initialized, open Session; serialize against Close.

Return Value

Independent Ada-owned capability values, not native owners.

Raised exceptions
Provider_Error

Closed Session, malformed capability data, provider exception or native allocation failure. Ada allocation or representation failures propagate after native cleanup.
