Description

Owned values of the pinned upstream @Optional NUC_TempData metadata, received through the opt-in NUC owners of AMS.MEL.IR.Image.Metadata and AMS.MEL.IR.Health_Status.Metadata. Every publicly readable TempPoint field is copied. The pinned TempPoint also stores an optional tempError, but upstream declares no public accessor for it; it is deliberately not represented, inferred or reported here.

Not_Supported

Not_Supported : exception;

The provider answered NotSupported for the optional NUC_TempData registration. The existing metadata owners of the same channel are unaffected.

NUC_Temp_Data

type NUC_Temp_Data is record
   Points : Temp_Point_Vectors.Vector;
end record;

Owned complete ordered getTempPoints() collection; empty messages have no points. The value is independent of the owner, channel, Session and provider library.

Record fields

Copied points in the order supplied by the provider.

Temp_Point

type Temp_Point is record
   Timestamp_NS  : Long_Long_Integer;
   Frame_Band    : AMS.MEL.IR.Channel.Band_Info;
   Pixel         : Pixel_Value;
   Temperature_K : Long_Float;
   Point_Type    : Temp_Point_Type;
end record;

Owned copy of every publicly readable TempPoint field. The inaccessible upstream tempError is not a component: absence here is not a claim that no error exists.

Record fields
Timestamp_NS

Signed nanosecond count, unconverted; clock and epoch unspecified.

Frame_Band

Band type and vacuum wavelength limits, in meters, of the point.

Pixel

Point pixel value with its original integer width.

Temperature_K

Temperature of the pixel value in Kelvin, copied without checks.

Point_Type

Upstream classification of the point.

Temp_Point_Type

type Temp_Point_Type is (NUC_Point, MFA_Estimate, Other);

Exactly the three pinned TempPointType alternatives; unknown values are rejected.

Enumeration Literal
NUC_Point

Point measured in the MFA's NUC process, upstream value 0.

MFA_Estimate

Point interpolated or extrapolated from supplier data or NUC points.

Other

Invalid or unsubstantiated point, upstream value 2.
