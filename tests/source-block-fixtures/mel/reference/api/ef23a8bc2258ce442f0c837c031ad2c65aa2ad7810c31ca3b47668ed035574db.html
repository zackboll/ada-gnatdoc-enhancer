Description

Safe Scheduling attachment and lifecycle only. Serialize public operations and Close on a shared typed owner externally.

As_Channel

function As_Channel (Channel : Scheduling_Channel) return AMS.MEL.IR.Channel.View

Allocate a weak common view (KeepAlive, CommsTest, Capabilities) without changing lifecycle. Closing the view leaves this owner intact; closing this owner makes later view operations fail. Admitted common requests retain their own lifetime and use Scheduling-only request accounting.

Parameters
Channel

Open Scheduling owner to reference weakly.

Return Value

Weak common view; its handle presence does not prove target existence.

Capabilities

function Capabilities
  (Channel : Scheduling_Channel) return AMS.MEL.IR.Channel.Channel_Capability

Copy provider capabilities while Attached or Enabled. Task_Schedule_Depth is reported verbatim; zero is a valid mode in which the application manages task priority and does not mean Scheduling is unsupported. A closed/failed lifecycle or conversion failure raises a provider error.

Parameters
Channel

Eligible Scheduling owner, externally serialized against Close.

Return Value

Owned snapshot valid after channel, Session and provider closure.

Close

procedure Close (Channel : in out Scheduling_Channel)

Stop public admission and close the owner without cancelling futures. There is no separate Disable: Close calls the inherited provider disable only if Enable was attempted, then detaches. Physical teardown waits for admitted common requests. A detach failure retains the graph and handle for retry; a disable failure after a successful detach still raises.

Parameters
Channel

Scheduling owner to close; serialize against its public operations.

Enable

procedure Enable (Channel : in out Scheduling_Channel)

Explicitly call the inherited Channel enable on an Attached owner; an already Enabled owner is idempotent. Provider refusal or exception raises a provider error and marks failure; retrying Enable does not recover it. Enabling does not submit, queue or schedule any task.

Parameters
Channel

Open Attached or already Enabled owner; serialize owner operations.

Is_Open

function Is_Open (Channel : Scheduling_Channel) return Boolean

Test local handle presence, not lifecycle eligibility or provider support.

Parameters
Channel

Scheduling owner to inspect without provider access.

Return Value

True for a present native handle, even if lifecycle has failed.

Open

function Open (Parent : Session; Config : Scheduling_Config) return Scheduling_Channel

Require an open Session that publishes the Scheduling category, attach once with ChannelType Scheduling (value 3), and verify the concrete SchedulingChannel interface and its advertised category. Configuration text is validated natively. Failure raises a provider error and no owner escapes; an ownership-uncertain incompatible attachment stays retained.

Parameters
Parent

Open Session whose native graph is retained by the child.

Config

Owned attachment values copied before provider use.

Return Value

Attached, not Enabled, Scheduling owner.

Scheduling_Channel

type Scheduling_Channel is limited private;

Limited controlled owner of an attached provider Scheduling channel. It retains the native Session graph and provider library independently of the parent Ada Session. Admitted common requests keep their own native lifetime and can defer physical teardown after public closure. Finalization is non-raising.

Scheduling_Config

type Scheduling_Config is private;

Owned channel/platform UCI identities and sensor component location for a Scheduling attachment; creating a value performs no provider operation.
