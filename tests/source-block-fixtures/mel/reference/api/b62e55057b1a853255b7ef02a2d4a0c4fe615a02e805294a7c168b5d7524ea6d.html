Description

Owned values of the pinned upstream @Optional OpticalDistortionMap, received through the opt-in Optical_Distortion_Map_Stream owner of AMS.MEL.IR.Image.Metadata. Every published getter is copied: five unsigned 32-bit values, four double extrema and the complete FRD and RowCol collections. Values are independent of the native event, image stream, Session and provider library. The two collections are independent of each other and of the scalar dimensions: no length equality or product relation is assumed and no element is inferred. Long_Float components carry the provider IEEE doubles unchanged: finite, negative and signed-zero values are exact. Infinity and NaN are also carried unchanged, never replaced by zero or a substitute, but they are not valid Ada scalar values: callers must test them with 'Valid or IEEE comparisons before checked arithmetic. NaN payload bits are not promised.
