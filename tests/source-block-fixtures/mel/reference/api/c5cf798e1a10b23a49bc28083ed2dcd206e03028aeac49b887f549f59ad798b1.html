Description

Complete owned values for the pinned optional CalibrationStatusCmd and CalibrationStatus. No Request_ID correlation, calibration execution, epoch or response deadline is asserted.

Calibration_Result

type Calibration_Result is (Not_Set, Completed, Failed, Interrupted, Not_Calibrated);

Exactly pinned values 0 .. 4. MaxExclusive (5) and future values are rejected, never remapped.

Enumeration Literal
Not_Set

Upstream NotSet (0), a meaningful unset result.

Completed

Upstream Completed (1).

Failed

Upstream Failed (2).

Interrupted

Upstream Interrupted (3).

Not_Calibrated

Upstream NotCalibrated (4).
