Description

Optional C2 EraseCommand values. A successful asynchronous return does not verify physical erasure: the pinned interface defines no such verification.

Erase_Request

type Erase_Request is new AMS.MEL.IR.Erase_Request_Owner with private;

Limited controlled observer; finalization never raises. Provider execution retains the native C2/Session/provider graph independently of this observer.

Erase_Result

type Erase_Result is private;

Owned Success or explicit MEL Rejected result. Provider/payload/cleanup failures raise Provider_Error, not a MEL rejection or successful result.
