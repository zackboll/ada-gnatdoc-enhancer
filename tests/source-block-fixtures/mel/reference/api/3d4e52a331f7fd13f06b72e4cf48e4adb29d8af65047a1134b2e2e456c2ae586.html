Description

Canonical owned values and request result for the pinned upstream CameraCommand and CameraCommandResp (@RequiredIfCameraCtrl). One definition is shared by the independent C2.Submit_Camera_Command and Image.Submit_Camera_Command operations and by the opt-in Image.Metadata CameraCommandResp owner. No physical limits, timestamp normalization or command substitution are applied by the bridge.

Camera_Command

type Camera_Command is record
   ID                  : Command_ID := 0;
   System_Time_NS      : Nanoseconds := 0;
   Kind                : Image_Type := Staring;
   Width               : Unsigned_32 := 0;
   Height              : Unsigned_32 := 0;
   Frame_Rate_Hz       : Unsigned_32 := 0;
   Integration_Time_NS : Nanoseconds := 0;
   Row_Offset          : Unsigned_32 := 0;
   Column_Offset       : Unsigned_32 := 0;
   Direction           : Scan_Direction := Negative_To_Positive_Azimuth;
   Number_Of_Stages    : Unsigned_32 := 0;
end record;

Owned copy of all eleven CameraCommand fields; defaults equal the upstream defaults.

Record fields
ID

Unique command identifier supplied by the caller.

System_Time_NS

System time for this command, signed nanoseconds.

Kind

Requested framing mode.

Width

Requested window width in pixels; must be within the system upstream.

Height

Requested window height in pixels; must be within the system upstream.

Frame_Rate_Hz

Requested frame rate in hertz.

Integration_Time_NS

Requested integration time, signed nanoseconds.

Row_Offset

Row offset of the frame start in sensor coordinates.

Column_Offset

Column offset of the frame start in sensor coordinates.

Direction

When scanning, the direction to scan.

Number_Of_Stages

When scanning, the number of TDI stages to use.

Camera_Command_Response

type Camera_Command_Response is record
   ID              : Command_ID := 0;
   Size            : Unsigned_32 := 0;
   Timestamp_NS    : Nanoseconds := 0;
   Command_Success : Boolean := False;
end record;

Owned copy of all four CameraCommandResp fields, independent of native owners.

Record fields
ID

Command identifier reported by the MFA.

Size

Upstream size value, copied without interpretation.

Timestamp_NS

Response timestamp, signed nanoseconds.

Command_Success

True when the MFA satisfies all requested parameters. False is a normal completed response, never an asynchronous MEL rejection.

Camera_Request

type Camera_Request is new AMS.MEL.IR.Camera_Request_Owner with private;

Limited request owner returned by C2/Image Submit_Camera_Command. Pending native work retains its channel, Session and provider library after request/channel/Session closure; finalization is non-raising and Close never cancels provider work.

Camera_Result

type Camera_Result is private;

Owned terminal request result: a response or an explicit rejection. Provider exceptions, null successful responses, unknown error codes and deferred cleanup failure raise exceptions rather than becoming results.

Close

Image_Type

type Image_Type is (Staring, Scanning);

Exactly the two meaningful pinned ImageType imaging modes. The upstream Reserved13 discriminator is deliberately not representable and is never sent by this binding.

Enumeration Literal
Staring

Staring framing mode, upstream value 0.

Scanning

Scanning framing mode, upstream value 1.

Wait

function Wait (Request : Camera_Request; Timeout_Milliseconds : Natural) return Camera_Result

Wait finitely for the terminal result. Timeout raises Timeout_Error and neither consumes nor cancels the request; repeated terminal waits return the cached result.

Parameters
Request

Open request; must not race Close.

Timeout_Milliseconds

Maximum wait; zero polls.

Return Value

Owned terminal response or explicit rejection.

Raised exceptions
Timeout_Error

The request is still pending.

Provider_Error

Closed owner, provider/future exception, null response, unknown error code, deferred cleanup failure or native failure.
