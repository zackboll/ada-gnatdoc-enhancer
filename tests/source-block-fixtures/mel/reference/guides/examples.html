Executable Ada Examples

These nine complete public-Ada programs are compiled and executed in the documentation workflow. Listings are highlighted directly from their canonical files, not separately pasted snippets. Supporting source expands without JavaScript. Supported public MEL package, type and unambiguous operation references within the listings are clickable links to verified native API documentation. Find the project, manifest, runner and all source under docs/examples/ in your checkout. See Getting Started for Linux, Alire, GNAT/GPRbuild, CMake, Python 3 and C/C++ compiler prerequisites.

From the repository root, build the production facade, separate existing mocks, and every example, then execute all run cases:

sh docs/examples/run.sh

Every individual command below also builds the collection. After that first build, append --no-build to run without rebuilding. Each program accepts exactly two arguments: a provider shared-library path and its configuration. The runner supplies absolute mock paths from native/build-tests/test-providers and the fixture strings below. For example, after building:

LD_LIBRARY_PATH="$PWD/native/build/lib" docs/examples/bin/owned_image \
  "$PWD/native/build-tests/test-providers/libmock_ir_provider.so" full-frame-rich

The runner removes inherited loader/preload and AMS_MEL settings, selects native/build/lib, checks ldd resolution and the facade's SHA-256 and exported-symbol inventory, inspects exit status and semantic observations, and inspects the actual child's loader initialization. A 15-second outer timeout guards each process. API waits are bounded to one second. Missing cases, unexpected rejections, timeouts and incorrect content fail the gate. No Squall, hardware, credentials, containers, provider downloads or private test entry points are used. Fixture identities are not deployment recommendations.

All owners have explicit successful-path closure and controlled, non-raising finalization fallback during exception unwinding. Top-level unexpected exceptions print their name and diagnostic and select an unsuccessful process exit. Serialize same-owner operations; read Ownership and Errors. Expected rejection cases return zero only after inspecting the documented rejection.

A. Provider session, snapshot and errors

AMS.MEL opens an IR Session and queries provider versions—not the facade ABI version. This mock supplies the exact version numbers, UTF-8 vendor and description checked below. The owned snapshot remains readable after Session Close. The missing-library case intentionally exits unsuccessfully with a loader diagnostic; its exact platform-specific path text can vary.

Complete canonical source: docs/examples/src/provider_session.adb

with Ada.Text_IO;
with AMS.MEL;
with Example_Support;

procedure Provider_Session is
   use Example_Support;
   use type AMS.MEL.Provider_Version_Number;
begin
   declare
      Session : AMS.MEL.Session := AMS.MEL.Open (Provider_Path, Configuration);
      Version : constant AMS.MEL.Provider_Version := AMS.MEL.Query_Provider_Version (Session);
   begin
      Require (AMS.MEL.API_Version (Version) = 16#1234_5678#, "mock API version");
      Require (AMS.MEL.Library_Version (Version) = 16#90AB_CDEF#, "mock library version");
      Require (AMS.MEL.Vendor (Version) = "Mock IR Provider µ", "mock vendor");
      AMS.MEL.Close (Session);
      Require (not AMS.MEL.Is_Open (Session), "Session still open");
      Require
        (AMS.MEL.Description (Version) = "Deterministic task 001 provider", "owned description");
      Ada.Text_IO.Put_Line ("vendor after Close: " & AMS.MEL.Vendor (Version));
      Ada.Text_IO.Put_Line ("description: " & AMS.MEL.Description (Version));
      Ada.Text_IO.Put_Line ("API=0x12345678 library=0x90ABCDEF");
   end;
exception
   when Error : others =>
      Report_Failure (Error);
end Provider_Session;

B. Owned complete IR image

AMS.MEL.IR constructs identities, location and bounded image configuration; AMS.MEL.IR.Image receives a complete Full_Frame. See IR Workflows. The supported stream path here is Mono8, single band—not every format in the vocabulary. The complete header and its associated validated payload are copied into one independent Ada value. The rich mock supplies 4-by-3 dimensions, two navigation states, sensor label, high-bit frame ID, signed time and pixels 160 through 171. Stop and Close do not invalidate that independently owned frame.

Complete canonical source: docs/examples/src/owned_image.adb

with Ada.Text_IO;
with AMS.MEL;
with AMS.MEL.IR;
with AMS.MEL.IR.Image;
with Example_Support;
with Interfaces;

procedure Owned_Image is
   package IR renames AMS.MEL.IR;
   package Image renames AMS.MEL.IR.Image;
   use Example_Support;
   use type Interfaces.Unsigned_32;
   use type IR.Byte;
begin
   declare
      Zero     : constant IR.UUID := [others => 0];
      Channel  : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example image");
      Platform : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example platform");
      Location : constant IR.Component_Location :=
        IR.Create_Component_Location (0.0, 0.0, 0.0, "station", "mock");
      Config   : constant IR.Image_Config :=
        IR.Create_Image_Config (Channel, Platform, Location, 3, 64, 4);
      Session  : AMS.MEL.Session := AMS.MEL.Open (Provider_Path, Configuration);
      Stream   : IR.Image_Stream := IR.Open_Image_Stream (Session, Config);
   begin
      IR.Start (Stream);
      declare
         Frame : constant Image.Full_Frame := Image.Receive (Stream, 1_000);
      begin
         Require (Image.Width (Frame) = 4 and then Image.Height (Frame) = 3, "mock dimensions");
         Require
           (Image.Bits_Per_Pixel (Frame) = 8 and then Image.Number_Of_Bands (Frame) = 1,
            "Mono8 single band");
         Require
           (Image.System_Time_NS (Frame) = -123456789
            and then Image.Frame_ID (Frame) = 16#FEDCBA98#
            and then Image.Sensor_Nav_State_Count (Frame) = 2
            and then IR.Key (Image.Contributing_Sensor_Value (Frame).Location) = "face-α",
            "rich complete-header metadata");
         IR.Stop (Stream);
         IR.Close (Stream);
         AMS.MEL.Close (Session);
         Require
           (Image.Pixel_Count (Frame) = 12
            and then Image.Pixels (Frame) (1) = 16#A0#
            and then Image.Pixels (Frame) (12) = 16#AB#,
            "owned pixels after Close");
         Ada.Text_IO.Put_Line ("4x3 Mono8; frame=0xFEDCBA98; nav states=2; sensor=face-α");
         Ada.Text_IO.Put_Line ("owned after Close: 12 pixels, first=160 last=171");
      end;
   end;
exception
   when Error : others =>
      Report_Failure (Error);
end Owned_Image;

C. Lease and scoped pixels

AMS.MEL.IR.Image retains frame payload storage in a limited lease. With_Pixels lends an array only during its synchronous processor invocation; do not retain it or race lease closure. This avoids an additional bulk Ada payload copy, not sensor-to-application or end-to-end zero-copy. Copy_Pixels explicitly obtains independent storage. The mock's twelve bytes, 16 through 27, sum to 258. Array attributes avoid assumptions about bounds.

Complete canonical source: docs/examples/src/frame_lease.adb

with Ada.Text_IO;
with AMS.MEL;
with AMS.MEL.IR;
with AMS.MEL.IR.Image;
with Example_Support;

procedure Frame_Lease is
   package IR renames AMS.MEL.IR;
   package Image renames AMS.MEL.IR.Image;
   use Example_Support;
   Sum : Natural := 0;
   procedure Sum_Pixels (Pixels : IR.Pixel_Array) is
   begin
      for Index in Pixels'Range loop
         Sum := Sum + Natural (Pixels (Index));
      end loop;
   end Sum_Pixels;
begin
   declare
      Zero     : constant IR.UUID := [others => 0];
      Channel  : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example lease");
      Platform : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example platform");
      Location : constant IR.Component_Location :=
        IR.Create_Component_Location (0.0, 0.0, 0.0, "station", "mock");
      Config   : constant IR.Image_Config :=
        IR.Create_Image_Config (Channel, Platform, Location, 3, 64, 4);
      Session  : AMS.MEL.Session := AMS.MEL.Open (Provider_Path, Configuration);
      Stream   : IR.Image_Stream := IR.Open_Image_Stream (Session, Config);
   begin
      IR.Start (Stream);
      declare
         Lease : Image.Frame_Lease := Image.Acquire_Frame (Stream, 1_000);
      begin
         Image.With_Pixels (Lease, Sum_Pixels'Access);
         Require (Sum = 258, "borrowed fixture pixel sum");
         declare
            Copy : constant IR.Pixel_Array := Image.Copy_Pixels (Lease);
         begin
            Image.Close (Lease);
            IR.Stop (Stream);
            IR.Close (Stream);
            AMS.MEL.Close (Session);
            Sum := 0;
            Sum_Pixels (Copy);
            Require (Copy'Length = 12 and then Sum = 258, "independent copy after Close");
            Ada.Text_IO.Put_Line
              ("borrow sum=258; independent copy after Close: 12 pixels sum=258");
         end;
      end;
   end;
exception
   when Error : others =>
      Report_Failure (Error);
end Frame_Lease;

D. Common capabilities and requests

AMS.MEL.IR.C2 owns the typed channel; its AMS.MEL.IR.Channel View is weak. Is_Open on a View only reports local handle presence, not whether its target still lives. Capability snapshots are independently owned. This attached-channel KeepAlive is permitted without Enable. A delayed mock may already have completed by the zero-duration poll: both immediate completion and Timeout_Error followed by bounded Wait are correct. Terminal results are cached. Timeout and request Close are not cancellation; closure abandons the observer, not provider work.

Complete canonical source: docs/examples/src/common_channel.adb

with Ada.Text_IO;
with AMS.MEL;
with AMS.MEL.IR;
with AMS.MEL.IR.C2;
with AMS.MEL.IR.Channel;
with Example_Support;

procedure Common_Channel is
   package IR renames AMS.MEL.IR;
   package C2 renames AMS.MEL.IR.C2;
   package Common renames AMS.MEL.IR.Channel;
   use Example_Support;
   use type Common.Outcome;
   use type Common.Command_Return;
   use type Common.Channel_Type;
begin
   declare
      Zero         : constant IR.UUID := [others => 0];
      Channel_ID   : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example common channel");
      Platform     : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example platform");
      Location     : constant IR.Component_Location :=
        IR.Create_Component_Location (1.25, -2.5, 3.75, "station", "mock");
      Config       : constant C2.Control_Config :=
        C2.Create_Config (Channel_ID, Platform, Location);
      Session      : AMS.MEL.Session := AMS.MEL.Open (Provider_Path, Configuration);
      Channel      : C2.Control_Channel := C2.Open (Session, Config);
      View         : Common.View := C2.As_Channel (Channel);
      Capabilities : constant Common.Channel_Capability := Common.Capabilities (View);
      Request      : Common.Return_Request := Common.Send_Keep_Alive (View);
      Result       : Common.Return_Result;
   begin
      Require
        (Common.Channel_Type_Count (Capabilities) = 1
         and then Common.Channel_Type_At (Capabilities, 1) = Common.Command_And_Control,
         "advertised common C2 capability");
      Ada.Text_IO.Put_Line ("capability: COMMAND_AND_CONTROL (owned snapshot)");
      --  Completion may win this poll. Timeout preserves this same request.
      begin
         Result := Common.Wait (Request, 0);
      exception
         when IR.Timeout_Error =>
            Require (Common.Is_Open (Request), "timeout consumed request");
            Result := Common.Wait (Request, 1_000);
      end;
      case Common.Status (Result) is
         when Common.Success  =>
            Require (Common.Value (Result) = Common.Return_Success, "KeepAlive payload");

         when Common.Rejected =>
            raise Program_Error with "KeepAlive rejected: " & Common.Description (Result);
      end case;
      declare
         Cached : constant Common.Return_Result := Common.Wait (Request, 0);
      begin
         Require (Common.Status (Cached) = Common.Success, "cached outcome");
         Require (Common.Value (Cached) = Common.Value (Result), "cached payload");
      end;
      Common.Close (Request);
      Common.Close (View);
      C2.Close (Channel);
      AMS.MEL.Close (Session);
      Require (Common.Channel_Type_Count (Capabilities) > 0, "owned capability after Close");
      Ada.Text_IO.Put_Line
        ("KeepAlive=RETURN_SUCCESS; cached result agrees; snapshot survives Close");
   end;
exception
   when Error : others =>
      Report_Failure (Error);
end Common_Channel;

E. Submit supplied navigation

AMS.MEL.IR.Image submits an application-supplied solution through an attached stream; Start is not required. This is not position estimation or a kinematics transformation. The clearly named fixture helper constructs the complete Navigation_Report, including all covariance terms. Radian/metre and nanosecond field names establish only those units; System_Time_NS has no established epoch. Fields such as Magnetic_Heading and Altitude_MSL retain their source values without invented units or conventions. Success and Rejected are checked before response or rejection access. Both fixture outcomes are run.

Complete canonical source: docs/examples/src/navigation_report.adb

with Ada.Text_IO;
with AMS.MEL;
with AMS.MEL.IR;
with AMS.MEL.IR.Image;
with Example_Support;
with Mock_Fixtures;
with Interfaces;

procedure Navigation_Report is
   package IR renames AMS.MEL.IR;
   package Image renames AMS.MEL.IR.Image;
   use Example_Support;
   use type Image.Navigation_Error_Code;
   use type Interfaces.Unsigned_32;
begin
   declare
      Zero     : constant IR.UUID := [others => 0];
      Channel  : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example navigation");
      Platform : constant IR.UCI_ID := IR.Create_UCI_ID (Zero, "example platform");
      Location : constant IR.Component_Location :=
        IR.Create_Component_Location (0.0, 0.0, 0.0, "station", "mock");
      Config   : constant IR.Image_Config :=
        IR.Create_Image_Config (Channel, Platform, Location, 2, 64, 2);
      Session  : AMS.MEL.Session := AMS.MEL.Open (Provider_Path, Configuration);
      Stream   : IR.Image_Stream := IR.Open_Image_Stream (Session, Config);
      --  The helper constructs every field, including all 18 covariance terms.
      Supplied : constant Image.Navigation_Report := Mock_Fixtures.Navigation_Fidelity_Report;
      Request  : Image.Navigation_Request := Image.Submit_Navigation_Report (Stream, Supplied);
      Result   : constant Image.Navigation_Result := Image.Wait (Request, 1_000);
   begin
      --  The stream is attached; no Start is required for this submission.
      case Image.Status (Result) is
         when Image.Success  =>
            declare
               Response : constant Image.Navigation_Response := Image.Response (Result);
            begin
               Require
                 (Response.System_Time_NS = -8_765_432_109
                  and then Response.Command_ID = 16#F123_4567#
                  and then Response.Request_ID = 16#89AB_CDEF#,
                  "mock navigation response");
               Ada.Text_IO.Put_Line ("navigation SUCCESS: command=0xF1234567 request=0x89ABCDEF");
            end;

         when Image.Rejected =>
            Require
              (Image.Rejection_Code (Result) = Image.Invalid_Parameters
               and then Image.Description (Result) = "invalid navigation report",
               "mock rejection");
            Ada.Text_IO.Put_Line ("navigation REJECTED: " & Image.Description (Result));
      end case;
      Image.Close (Request);
      IR.Close (Stream);
      AMS.MEL.Close (Session);
   end;
exception
   when Error : others =>
      Report_Failure (Error);
end Navigation_Report;

I. ProductRx receive, borrow and copy

AMS.MEL.RF.Product_Rx creates a bounded Complex INT16 endpoint under AMS.MEL.RF. The mock rx:ok:sync delivers during registration, potentially before Claim returns; plain rx:ok needs a private emitter and is deliberately not used. Sample counts represent I/Q pairs. Native callback samples have already been copied by the bridge. With_Samples calls the application processor synchronously; its borrow ends when that processor returns. Copy_Samples supplies independently owned Ada storage; borrowed and copied lower bounds can differ, so iteration uses Range. The exact two pairs are validated after all native owners close. Statistics are read while the endpoint remains open. After its sole event is consumed, zero-time Receive deterministically demonstrates an empty-queue timeout. The rejection case checks Failed before error accessors.

with Ada.Text_IO;
with AMS.MEL.RF;
with AMS.MEL.RF.Product_Rx;
with Example_Support;
with Interfaces;

procedure RF_Product_RX is
   package RF renames AMS.MEL.RF;
   package RX renames AMS.MEL.RF.Product_Rx;
   use Example_Support;
   use type RF.Job_Data_Format;
   use type Interfaces.Integer_16;
   use type Interfaces.Unsigned_32;
   use type RX.Create_Error_Code;
   use type RX.Counter;
   Sum : Integer := 0;
   procedure Process (Samples : RX.Complex_I16_Array) is
   begin
      for Index in Samples'Range loop
         Sum := Sum + Integer (Samples (Index).Real);
      end loop;
   end Process;
begin
   declare
      Data    : RF.Data_MEL := RF.Open (Provider_Path, Configuration);
      Config  : constant RX.Config := RX.Create_Config (65_536, 4, 16);
      Request : RX.Create_Request := RX.Submit (Data, Config);
      Result  : constant RX.Create_Result := RX.Wait (Request, 1_000);
   begin
      case RX.Outcome (Result) is
         when RX.Failed  =>
            Require
              (RX.Error_Code (Result) = RX.Insufficient_Resources
               and then RX.Description (Result) = "mock ProductRx resources exhausted",
               "mock creation rejection");
            Ada.Text_IO.Put_Line ("ProductRx FAILED: " & RX.Description (Result));

         when RX.Created =>
            declare
               --  Registration inside Claim may deliver before Claim returns.
               Endpoint : RX.Endpoint := RX.Claim (Request);
               Event    : RX.Event := RX.Receive (Endpoint, 1_000);
               Metadata : constant RX.Product_Metadata := RX.Metadata (Event);
            begin
               Require
                 (RX.Data_Format (Event) = RF.Complex_INT16 and then RX.Sample_Count (Event) = 2,
                  "Complex INT16 pair count");
               Require
                 (RX.Job_Details_ID (Metadata) = 16#DEAD_BEEF#
                  and then RX.MEL_Protocol_Version_ID (Metadata) = 16#FEDC_BA98#,
                  "copied ProductRx metadata");
               RX.With_Samples (Event, Process'Access);
               Require (Sum = 76, "borrowed real sum");
               declare
                  Copy : constant RX.Complex_I16_Array := RX.Copy_Samples (Event);
               begin
                  RX.Close (Event);
                  Require (RX.Statistics (Endpoint).Products_Queued = 1, "sole queued product");
                  begin
                     declare
                        Unexpected : RX.Event := RX.Receive (Endpoint, 0);
                     begin
                        RX.Close (Unexpected);
                        raise Program_Error with "expected empty-queue timeout";
                     end;
                  exception
                     when RX.Timeout_Error =>
                        Ada.Text_IO.Put_Line ("empty queue: Timeout_Error (endpoint remains open)");
                  end;
                  RX.Close (Endpoint);
                  RX.Close (Request);
                  RF.Close (Data);
                  Require
                    (Copy'Length = 2
                     and then Copy (Copy'First).Real = 77
                     and then Copy (Copy'First).Imag = -77
                     and then Copy (Copy'Last).Real = -1
                     and then Copy (Copy'Last).Imag = 1,
                     "independent actual sample pairs after Close");
                  Sum := 0;
                  Process (Copy);
                  Require (Sum = 76, "independent sum");
                  Ada.Text_IO.Put_Line
                    ("Complex INT16 pairs after Close: (77,-77) (-1,1); real sum=76");
                  Ada.Text_IO.Put_Line ("metadata Job_Details_ID=0xDEADBEEF; products queued=1");
               end;
            end;
      end case;
      RX.Close (Request);
      RF.Close (Data);
   end;
exception

with Ada.Command_Line;
with Ada.Text_IO;

package body Example_Support is
   function Provider_Path return String is
   begin
      if Ada.Command_Line.Argument_Count /= 2 then
         raise Constraint_Error with "usage: program PROVIDER_LIBRARY MOCK_CONFIGURATION";
      end if;
      return Ada.Command_Line.Argument (1);
   end Provider_Path;

   function Configuration return String
   is (Ada.Command_Line.Argument (2));

   procedure Require (Condition : Boolean; Message : String) is
   begin
      if not Condition then
         raise Program_Error with Message;
      end if;
   end Require;

   procedure Report_Failure (Error : Ada.Exceptions.Exception_Occurrence) is
   begin
      Ada.Text_IO.Put_Line
        (Ada.Text_IO.Standard_Error,
         Ada.Exceptions.Exception_Name (Error) & ": " & Ada.Exceptions.Exception_Message (Error));
      Ada.Command_Line.Set_Exit_Status (Ada.Command_Line.Failure);
   end Report_Failure;
end Example_Support;
