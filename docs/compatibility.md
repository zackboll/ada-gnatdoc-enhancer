# Compatibility and evidence levels

| Feature | Bootstrap qualification |
| --- | --- |
| Installable Python CLI, theme, local CSS/JS | Implemented; offline synthetic fixtures |
| Deterministic highlighting, local type hyperlinks | Implemented; synthetic source/native identities |
| Package/operation navigation and browser URL support | Implemented; automated structural/JS tests; real browser subject to local availability |
| HTML portal with 29-package MEL mock inventory | Implemented; synthetic pages, six guide slots |
| Strict Markdown guide rendering | Optional pinned renderer; no real compiled-example certification |
| Warnings and declaration coverage | Partial generic reporting; full consumer ratchets remain local |
| Core generic-instance summaries | Deferred; source- and template-specific invariants needed |
| Complete Core/Imgproc/Geometry/MEL output byte-parity | **Not qualified** |
| GNATdoc other than 26.0.0 | Unsupported |
| Cross-repository externally verified Core anchors | Consumer adapter must supply and qualify target map |

No application runtime depends on the enhancer. Consumer sites are produced
entirely offline. Future adoption requires separate pinned, exact-site tests,
reviewed exceptions where applicable and existing compiler/provenance checks.
